# 交通运输物流行业投资研究报告

> 编制日期:2026年7月9日|数据来源:websearch.py(Bing)、东方财富datacenter、腾讯行情、baidu估值

## 一、行业现状(2026-07-09最新)

### 1.1 市场规模与增速

根据国家统计局2025年统计公报(2026年2月28日发布),2025年全国货物运输总量596.7亿吨,同比增长3.2%;货物运输周转量27.42万亿吨公里,增长4.6%。交通运输、仓储和邮政业增加值6.21万亿元,增长5.2%,高于GDP增速(5.0%)。2025年全国社会物流总额超368万亿元,社会物流总费用与GDP比率降至历史最低水平,物流降本增效成效显著。

分运输方式看:公路货运432.9亿吨(+3.4%)、水路货运101.2亿吨(+3.2%)、铁路货运52.8亿吨(+2.0%)、民航货运1017.2万吨(+13.3%,增速最快)、管道货运9.7亿吨(+1.1%)。港口完成货物吞吐量183亿吨(+4.2%),其中外贸货物吞吐量57亿吨(+4.7%);港口集装箱吞吐量3.54亿标准箱(+6.8%)。网上零售额15.97万亿元(+8.6%),电子商务交易额46.75万亿元(+2.5%),持续支撑快递物流需求。

2025年人民币平均汇率7.1429元/美元(贬值0.3%),对航空(外币负债与燃油成本)和航运(美元结算)均有影响。

### 1.3 供需分析

**快递**:需求侧受网上零售(+8.6%)和直播电商持续渗透支撑,2025年快递业务量维持双位数增长。供给侧方面,行业价格战2025年下半年有所缓和,韵达2025年报净利大幅下滑(-38.8%)反映此前价格竞争对盈利的冲击;2026Q1通达系利润集体修复(申通+94.3%、圆通+60.8%、韵达+51.7%),表明行业竞争格局改善、单票利润企稳回升。

**航运**:集运供给侧受红海绕行持续(2025年大部分时段船舶绕行好望角)、新船交付有限支撑;2026年6月SCFI连续九周上涨至3239.64点,美西线6067美元/FEU(+6.76%)、美东线7384美元/FEU(+7.43%)、欧洲线3342美元/TEU(+5.83%)、地中海线4666美元/TEU(+9.53%)。油运方面,2026年6月霍尔木兹海峡"解封"引发VLCC运价飙升至38万美元/天以上,波斯湾至印度航线达897个Worldscale点。干散货方面,BDI处于震荡区间。

**航空**:需求侧国际航线持续恢复,2026Q1国航净利+183.9%大幅扭亏,春秋净利+45.2%。供给侧飞机引进受限(波音/空客交付延迟),供给增速低于需求恢复速度,客座率提升。但油价高位及人民币波动对成本端形成压力。

**港口**:2025年集装箱吞吐量+6.8%,外贸吞吐量+4.7%。2026Q1上港集团营收+8.0%、宁波港营收+15.6%,吞吐量增长强劲。供给侧港口整合持续推进,产能利用率提升。

### 1.4 政策环境

1. **十五五规划开局之年**:2026年是"十五五"规划第一年,交通运输领域基建投资保持强度,聚焦综合交通枢纽、多式联运、智慧物流等方向。
2. **物流降本增效**:国家持续推进全社会物流降本增效专项行动,社会物流总费用与GDP比率降至历史最低,政策目标进一步压降至14%以内。
3. **海运强国战略**:交通运输部推进港口资源整合、航运业高质量发展,支持央企航运公司提升国际竞争力。
4. **民航市场化改革**:航线时刻管理改革、国际航权优化配置、低空经济政策推进(2025年低空经济纳入国家战略)。
5. **绿色低碳**:船舶LNG/甲醇燃料替代、港口岸电使用、新能源物流车推广,碳交易体系覆盖航运。

### 1.5 周期位置

当前行业处于**分化复苏期**:快递处于竞争格局改善后的盈利修复上行期;集运处于高运价景气延续期(SCFI九连涨)但同比2025年峰值有所回落;油运处于地缘事件驱动的脉冲高景气期;航空处于国际航线恢复驱动的扭亏上行期;港口处于吞吐量稳健增长期;铁路/公路处于防御性稳定期。整体看,行业景气度自2025年四季度触底后,2026年上半年进入温和复苏通道。

### 1.6 细分深度

**快递**:2025年快递业务量延续高增长(预计超2000亿件),行业CR8集中度稳定。顺丰定位中高端商务件+国际件,通达系聚焦电商件。2026Q1单量增速:申通最快(+30.7%营收增速)、圆通次之(+10.0%)、顺丰稳健(+6.1%)、韵达偏弱(+3.2%)。竞争格局从"价格战"向"品质竞争"转变,单票收入企稳。顺丰鄂州花湖机场货运枢纽产能持续释放,国际全货机航线网络扩展。

**航空**:三大航(国航/东航/南航)2025年延续亏损(国航2025年报净利大幅亏损),但2026Q1国航扭亏(净利+183.9%),显示国际航线恢复带动业绩拐点。春秋航空作为低成本航空龙头,PE16.91、Q1净利+45.2%,客座率和成本控制能力行业领先。2026年夏秋航季国际航班量预计恢复至2019年同期80%以上,中美航线增班持续推进。

**港口**:上港集团(PE8.64,市值1178亿)为全球最大集装箱港口运营商,2026Q1营收+8.0%。宁波港(PE12.28)2026Q1营收+15.6%,区域港口整合效果显现。港口费率市场化改革推进,外贸吞吐量受益于出口韧性。

**航运**:中远海控(PE8.49,PB0.91破净)为全球集运龙头,2026Q1净利-49.8%因运价同比回落,但SCFI九连涨预示Q2/Q3环比改善可期。公司保持高分红政策(股息率约7-8%)。VLCC油运方面,招商轮船(未在表中)受益于地缘事件驱动的运价暴涨。

**铁路**:京沪高铁(PE16.93,PB1.08)为高铁核心资产,2026Q1净利+6.0%,客流稳健恢复,票价市场化机制提供弹性。2025年全年铁路客运量预计超40亿人次,恢复至2019年水平以上。

**公路**:招商公路(PE14.13)为公路收费平台型公司,投资控股多条高速;宁沪高速(PE13.36)为长三角高速龙头,高股息防御属性突出。公路货运2025年432.9亿吨(+3.4%),车流量温和恢复。

## 二、未来发展方向

### 方向一:快递国际化与供应链服务(2026-2028)

中国快递企业加速出海,顺丰国际全货机网络覆盖东南亚、欧洲、美洲;圆通国际航线拓展;极兔东南亚市占率提升。跨境电商(B2C出口)2025年规模超2万亿元,带动跨境物流需求年均增长15-20%。顺丰鄂州机场、圆通嘉兴全球航空物流枢纽将成关键节点。预计2028年中国快递企业国际业务收入占比从当前约8%提升至15%以上。

### 方向二:多式联运与物流数字化(2026-2030)

国家推进铁水联运、公铁联运,目标到2030年集装箱铁水联运量年均增长10%以上。智慧物流方面:无人仓、无人车配送在快递末端加速落地(顺丰、京东物流已规模化部署);区块链溯源在冷链物流应用;AI路径优化降低空驶率。物流数字化市场规模预计2028年突破3000亿元。

### 方向三:绿色航运与新能源船舶(2026-2032)

国际海事组织IMO 2030减排目标驱动船舶绿色化:LNG双燃料船订单占比超40%,甲醇/氨燃料船舶开始试航。中远海控订造新一代绿色船舶;港口岸电覆盖率目标2028年达80%。碳交易体系2026年覆盖航运业,绿色溢价将重塑运价体系。中国造船业在全球绿色船舶订单中份额超50%。

### 方向四:低空经济与无人机物流(2026-2030)

2025年低空经济纳入国家战略,2026年进入政策落地期。无人机配送在偏远地区、医疗急救、同城即时配送场景加速商业化(顺丰丰翼、美团无人机已在深圳等城市常态化运营)。eVTOL城市空中交通预计2027-2028年实现商业首飞。低空经济市场规模预计2030年达万亿元级。

### 方向五:航空国际航线全面恢复与枢纽升级(2026-2027)

中美航线2026年增班至每周100班以上(vs 2019年每周300班),中欧航线基本恢复。上海机场(浦东+虹桥)、白云机场国际客流量2026年预计恢复至2019年90%以上,免税收入回升。国内二线机场国际航线开拓带来增量。机场免税经营模式改革(中免与机场分成调整)有望释放利润。

### 3.2 评级

- **超配**:快递(竞争格局改善+量增价稳)、航运(高运价延续+低估值高股息)
- **标配**:航空(国际恢复但估值偏高)、港口(稳健增长+低估值)、铁路(防御性)
- **低配**:公路(成长性不足,纯防御配置)、机场(估值偏高,等待业绩兑现)

### 3.3 配置框架

推荐"核心-卫星"配置:核心仓位(60%)配置顺丰控股+中远海控+京沪高铁,兼顾成长性与安全边际;卫星仓位(30%)配置圆通速递+春秋航空+申通快递,博取高弹性;防御仓位(10%)配置招商公路+上港集团,高股息对冲波动。

细分赛道优先级:快递(竞争格局改善最确定)>航运(SCFI高景气+破净估值)>航空(扭亏弹性大但估值偏高)>港口(稳健增长)>铁路(稳定防御)>公路(纯防御)。

### 3.4 减仓退出触发

1. SCFI连续3周下跌超过10%,减仓中远海控50%
2. 快递行业单票收入同比转负(价格战重启),减仓通达系至30%
3. 国际油价突破90美元/桶,减仓航空股至20%
4. 人民币升值突破6.90(侵蚀航运美元收入),减仓中远海控30%
5. 顺丰股价突破38元(目标价),分批止盈
6. 春秋航空客座率连续2个月低于85%,减仓50%

## 四、跨行业关联

1. **电商零售**:网上零售额(+8.6%)直接驱动快递业务量,直播电商/跨境电商渗透率提升是快递增量核心。
2. **石油化工**:国际油价直接影响航空燃油成本(占航司成本30-40%)及航运燃料成本,油价波动是航空/航运利润最大变量。
3. **造船/机械**:绿色船舶订单潮利好中国造船业(中国船舶等),港口自动化设备需求利好工程机械。
4. **房地产/基建**:交通基建投资(高铁、公路新建)拉动建材需求,物流园区开发关联商业地产。
5. **信息技术**:智慧物流(无人仓、AI调度、区块链溯源)拉动服务器、物联网设备、5G专网需求。
6. **旅游酒店**:航空/高铁客流恢复直接利好旅游目的地消费,机场免税关联免税零售。
7. **金融保险**:航运保险(船壳险、货运险)、航空保险(机身险、责任险)随运输量增长而扩容。

## 五、风险提示

1. **地缘政治风险**:红海危机、霍尔木兹海峡局势、中美贸易摩擦等可能骤变,集运/油运运价波动剧烈。
2. **价格战重启风险**:快递行业若再度陷入恶性价格竞争,通达系单票利润将受严重冲击(参照2025年韵达净利-38.8%先例)。
3. **油价飙升风险**:若国际油价突破100美元/桶,航空业将重回亏损(燃油占成本30-40%),航运利润亦被侵蚀。
4. **汇率波动风险**:人民币大幅波动影响航空(外币负债+海外燃油采购)和航运(美元结算收入)的汇兑损益。
5. **宏观经济下行风险**:GDP增速放缓将直接拖累货运量、快递量、航空客流,行业β属性较强。
6. **政策变动风险**:高速公路收费期限调整、港口费率管制、民航时刻分配改革等政策变动影响相关公司盈利。
7. **新产能投放风险**:集运新船2026-2027年集中交付,若红海恢复正常通行,运力过剩将压制运价。
8. **安全事件风险**:航空安全事故、港口碰撞漏油、铁路运行事故等黑天鹅事件可能冲击个股及行业。
