## 一、这是什么

一个**自上而下**的A股投资研究项目，分三步：
1. **Step1 全行业调研**：36个行业逐个从零独立调研（现状/竞争格局/标的/SOTA技术/评级）
2. **Step2 板块选取**：判市场阶段 → 36行业评分排名 → 选板块 + 供应链串联
3. **Step3 个股选取**：在关注板块内独立选股 + 五点制买卖点（建仓/止损/目标）+ 前瞻情景 + 组合落地

核心理念：**个股受板块影响最大，选对板块赢大半；板块受市场阶段定调。** 所以先判阶段→选板块→选个股，自上而下。
