## 1. 行业景气度与现状(2026年8月中)

### 1.1 核心判断: 概念为主,商业化遥远,资本热潮但回报未验证

量子技术行业在2026年处于**技术突破密度最高的一年**,但同时也是**最需要清醒判断的一年**。三条主线清晰:

**量子计算——技术突破密集,商业答案缺位**

| 维度 | 现状(2026年8月) |
|---|---|
| 量子优越性 | 中国在光量子(九章系列)和超导(祖冲之系列)两条路线均实现优越性,全球唯一 |
| 量子纠错 | 2024年底谷歌Willow芯片首次实现"低于阈值";2025年合肥国家实验室验证"越纠越对";IBM证明实时纠错解码可行 |
| 容错时代预期 | 提前至2030年(比此前预测乐观5-10年),所需物理比特约1万-2万个 |
| 技术路线 | 七条并行(超导/离子阱/光量子/中性原子/硅基自旋/拓扑/光子),无收敛迹象 |
| 商业应用 | 至今无经过独立验证的商业答案,金融/医药/材料仍处早期探索 |
| NISQ阶段 | 当前仍为含噪声中等规模量子计算,数十至数百比特,噪声锁死计算深度 |

**量子通信——中国全球领先,工程化推进中**

- 2025年3月: 中国科大首次实现量子微纳卫星与可移动地面站间实时星地量子密钥分发(QKD),单次卫星通过期间实现100万比特安全密钥共享
- 2026年2月: 中国科大构建可扩展量子中继基本模块,远距离量子网络成为现实可能
- 2026年6月: 中国科大实现远距离芯片化量子通信网络
- 2026年8月: 量子存储器间纠缠距离提升至420公里
- 300公里级量子直接通信网络已构建

**量子测量——应用早期,传感器微型化**

- 国仪量子公司(未上市)研发钻石探针量子传感器,直径500纳米,传感器尺度在针尖上
- 2025年7月: 纳米双光子工厂制备保真度99.4%的新型量子纠缠光源

**结论: 宏观不匹配,概念板块当前无超额收益基础**

| 宏观指标 | 数值(2026-08-16) | 与量子板块相关性 |
|---|---|---|

**核心矛盾**: 量子技术是"十五五"规划前沿科技攻关三大核心方向之一(与AI/可控核聚变并列),政策催化明确。但当前市场风格为**防御占优**,进攻板块(科技/创新药)反弹已结束重新走弱。量子概念股普遍为高PE/亏损股(国盾PE 6303倍、中国长城扣非-6.5亿),与防御性市场风格严重不匹配。宏观环境下,概念炒作缺乏持续性资金支撑。

## 2. 竞争格局

### 2.1 (a) 国际维度——中美欧三极竞赛

| 维度 | 美国 | 欧盟 | 中国 |
|---|---|---|---|
| 政策框架 | 《2026国家量子计划重授权法案》延续至2034年 | "量子法案",500亿欧元Scaleup Europe Fund | "十五五"规划,量子科技列为前沿科技攻关核心 |
| 资金 | NIST年8500万美元;NSF新建3个量子中心;能源部5年6.25亿 | 德国2029年前180亿欧元;SUPREME联盟2500万欧元 | 举国体制,产业集群(合肥/北京/上海/深圳) |
| 核心企业 | IBM(Heron处理器/实时纠错);Google(Willow/低于阈值);IonQ(离子阱/18亿美元收购SkyWater);PsiQuantum(光子/百万比特目标2027) | Quantum Motion(硅基/1.6亿欧元C轮);Qblox(量子控制/2600万欧元) | 国盾量子(量子通信龙头);本源量子(超导整机);图灵量子/玻色量子(初创) |
| 技术路线侧重 | 超导(IBM/Google)+离子阱(IonQ)+光子(PsiQuantum) | 硅基(Quantum Motion)+超导(SUPREME) | 光量子(九章)+超导(祖冲之)+量子通信(卫星QKD) |
| 供应链安全 | 法案要求梳理量子供应链脆弱环节,设量子制造研究所 | 建设试点产线,提高供应链韧性 | 自主可控,全链条部署 |
| 特色 | 立法锚定长期投入,军方/情报深度参与 | 技术主权,产业联盟驱动 | 举国体制,产业集群初成 |

**国际差距判断**: 中国在量子通信领域全球领先(唯一实现星地QKD/可扩展量子中继);量子计算在光量子/超导两条路线均实现优越性,与美并跑;产业化/供应链成熟度落后于美国(IonQ已建制造工厂,PsiQuantum计划2027交付百万比特商用机)。

### 2.2 (b) 产业链图谱

```
上游(核心零部件)          中游(整机/系统/云服务)         下游(应用)
┌─────────────────┐     ┌───────────────────┐     ┌─────────────────┐
│ 稀释制冷机        │     │ 量子计算整机         │     │ 金融(投资组合优化)  │
│ 激光器/微波控制    │     │  -超导(本源/祖冲之)  │     │ 医药(分子模拟)     │

│ FPGA/控制系统      │     │  -离子阱(IonQ)      │     │ 密码安全(PQC迁移)  │
│ 单光子探测器       │     │  -中性原子(太一量生等)│     │ 汽车/制造          │
│ 光子芯片(光迅科技) │     │ 量子通信设备(国盾量子)│     │ 量子传感(国仪量子) │
└────────┬────────┘     │ 量子云服务平台        │     └─────────────────┘
         │              └─────────┬─────────┘
         │                        │
   本土供应商(频准激光/量曦技术     │ 软件生态(酉术量子/瀚海凌潮/
   /璇相科技等)                    │ 微观纪元等)
```

**产业链特点**:
- 上游供应链全球范围仍在成形中,中国本土供应商涌现但规模小
- 中游由初创企业和科技巨头主导,开发者可在线调用NISQ级量子计算资源
- 下游应用集中在金融/医药/材料/密码安全,均处早期探索阶段
- 资本从"硬件竞赛"转向"生态均衡",软件/算法/控制系统获更大投资比例

### 2.3 (c) 集中度CR3/CR5

**量子通信(中国市场)**:
- CR3: 国盾量子 + 科大国盾(未上市/合肥) + 问天量子(未上市/芜湖) → 集中度极高,国盾量子为唯一上市龙头
- 国盾量子2025年营收3.10亿元,在A股量子通信标的中唯一纯主业,但全行业营收规模仍小

**量子计算(全球市场)**:
- CR5(按融资/估值): IBM + Google + IonQ + PsiQuantum + 本源量子(中国/未上市)
- 七条技术路线并行,无统一标准,集中度分散,各路线头部企业尚在跑马圈地
- 中国上市量子计算标的稀缺,核心企业(图灵量子/玻色量子/本源量子/量旋科技)均未上市

**结论**: 量子通信集中度较高(国盾量子龙头);量子计算极度分散(七路线并行);A股可投标的稀缺,概念股多于实质标的。

### 2.4 (d) 产能周期

| 环节 | 产能阶段 | 判断 |
|---|---|---|
| 量子计算整机 | 实验室→产线过渡期 | IonQ/PsiQuantum建制造工厂,中国仍以实验室/研究院为主 |
| 量子通信设备 | 小批量商用 | 国盾量子营收3亿级,规模仍小,产能非瓶颈,需求是瓶颈 |
| 核心零部件 | 供应链成形中 | 稀释制冷机等关键设备依赖进口,本土供应商规模小 |
| 后量子密码(PQC) | 迁移启动期 | NIST标准化完成,美国要求2035年前迁移,中国密码学会启动征集 |

**产能周期判断**: 行业整体处于**从实验室到产线的过渡期**,不存在传统行业的产能过剩/出清周期。核心矛盾不是产能,而是**商业化需求尚未验证**——"量子计算机究竟能解决什么真实问题,行业至今没有给出经过独立验证的商业答案"。

- 净利: 2021年3.76亿→2022年2.07亿→2023年2.07亿→2024年-5.24亿→2025年0.56亿,2024年巨亏

- **造假前科/审计意见**: 无造假前科,审计意见待核实。

**结论**: 量子保密通信应用为边缘业务,主业IT服务。2024年巨亏5.24亿,2025年靠非经常性收益勉强扭亏(5643万净利但OCF为负)。大股东+高管近6月集中减持,负面信号明确。PE分位94-98%,估值偏高。不作为核心推荐标的。
