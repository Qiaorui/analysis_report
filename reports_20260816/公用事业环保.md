## 一、行业总览与宏观相关性分析

### 1.1 行业基本面总览

公用事业环保板块覆盖电力（水电、核电、火电、绿电）与环保（垃圾焚烧、固废、水务）两大主线，是A股典型的**防御性+类债资产**集合。截至2026年8月，板块运行呈现以下格局：

**电力供需与装机结构**：国家能源局2026年1月发布的数据显示，截至2025年底全国累计发电装机容量38.9亿千瓦，同比增长显著。其中非化石能源装机占比已过半，新型电力系统加速构建。"十五五"规划纲要明确加快构建清洁低碳安全高效的新型能源体系，央视2026年5月报道"十五五"时期电网总投资规模达5万亿元，2030年将初步建成全国互联新型电力系统。电力消费稳步增长，体现经济持续发展与电气化深化（low carbon power数据，2026年8月）。

**水电**：稀缺性资产。国家能源局2026年6月报道中国水电装机十年增长40%，"十五五"规划深入实施能源安全新战略。但行业研究指出，十三大水电基地中装机500万千瓦以上的增量水电站近乎为零，**优质大型水电站资源已近开发完毕，存量电站价值凸显**。水电总院正在解读《可再生能源发展"十五五"规划》（光热等篇），水风光互补模式加速新型能源体系建设。

**核电**：高景气审批周期。国家能源局2026年8月6日发布《中国核电发展报告（2026）》，截至2025年底中国在运和核准在建核电机组共112台。蓝皮书（2026年4月）披露商运机组60台、在建36台（在建规模占全球一半以上）。2024年核准11台，**连续3年核准机组数量超10台**，"十五五"进入投产高峰期。国家核安全局数据显示2025年全年核电运行辐射环境监测正常。

**环保（垃圾焚烧）**：产能过剩转折点。央视《焦点访谈》2025年12月7日报道"焚烧厂为何吃不饱"，直指垃圾处理能力过剩问题——前些年各地纷纷兴建垃圾焚烧发电厂，现已出现产能利用率不足。这是环保子行业最核心的负面产业周期信号，叠加国补退坡，行业从扩张期进入整合期。

### 1.2 宏观相关性分析（必答）

本板块与宏观变量的相关性是投资逻辑的核心，逐项分析：

**(1) 与利率的关系——类债资产定价锚**

水电、核电具备"长久期+稳定现金流+高股息"特征，本质是**类债资产**。其估值与无风险利率（十年期国债收益率）呈反向关系：利率下行期，稳定股息的相对吸引力上升，DCF估值中折现率下降推升远期现金流现值，板块获得"久期溢价"。当前时点（2026年8月），上证3927点跌破MA250空头排列，市场风险偏好回落，防御资产重新占优，长江电力近30日+3.88%、公用事业近30日+9.61%，正是利率敏感+避险双重驱动。若后续货币宽松延续（融资余额13550亿回流亦反映宽货币宽信用环境），类债资产估值有支撑；反之若利率超预期回升，则板块承压。

**(2) 与防御属性/上证的关系**

公用事业与上证指数呈**负相关/低相关**的防御特征：大盘下行时资金避险流入（"长江电力近30日+3.88%" vs 上证跌破MA250），大盘上行时资金追逐成长而板块跑输。当前上证跌破MA250、空头排列的市场环境下，板块的防御配置价值上升。但需注意：防御占优是**相对收益逻辑**，一旦市场企稳反弹（融资余额已回流13550亿显示风险偏好修复迹象），资金可能从防御板块撤出追逐弹性，板块存在"补跌/滞涨"风险。

**(3) 与油价的关系**

油价$77回落对火电（燃料成本下降利好）直接利好，但本报告聚焦的水电/核电属非化石能源，油价直接影响有限。间接影响在于：油价回落反映需求偏弱+通胀降温，强化宽松预期，间接利好类债资产估值。环保子行业与油价相关性弱。

### 1.3 本轮防御逻辑的可持续性判断

核心问题"高股息可持续性"：水电（长江电力）来水稳定+低成本+高现金流，股息可持续性强；核电（中国核电）处于资本开支投产期，折旧高、自由现金流尚未充分释放，股息率低于水电但成长性更优。当前防御逻辑成立但需警惕：①板块近30日已上涨9.61%，部分price-in；②若上证企稳，防御溢价回吐。

## 二、国际格局与全球产业链维度

### 2.1 全球水电格局

全球水电开发已进入成熟期，发达国家大型水电资源基本开发完毕（如美国、欧洲），增量主要集中在中国（十三大水电基地，但500万千瓦以上增量近乎为零）、东南亚（澜沧江-湄公河流域）、拉美（亚马逊支流）及非洲。中国在运水电装机居全球首位，十年增长40%。技术层面，水风光互补（水电+风电+光伏打捆外送）成为新型能源体系重要模式，中国在该领域处于领先实践阶段。

**产业链对标**：全球水电设备产业链（水轮机、发电机）集中度高，主要参与者包括GE水电（原阿尔斯通）、安德里茨、福伊特及东方电气/哈电集团。中国大型水电站设备国产化率极高，产业链自主可控。

### 2.2 全球核电格局——中国是唯一大规模扩张市场

这是核电子行业最重要的国际维度。全球核电自日本福岛事故后长期低迷，欧洲（德国退核）、北美增量有限，**中国是全球核电在建规模最大的国家**：蓝皮书披露在建36台占全球一半以上。这赋予中国核电产业链（核岛/常规岛设备、核燃料、工程建设）独特的成长性。

- **技术路线**：中国以压水堆（PWR）为主流，"华龙一号"自主三代技术已批量推广，"国和一号"CAP1400及高温气冷堆示范工程推进。国家能源局报告提及"华能首台"机组进展，反映华能集团参股核电的新格局。
- **全球对标**：对标法国EDF（核电主导运营商）、韩国KHNP（APR1400出口），中国核电度电成本与利用小时数具备竞争力，但电价市场化程度是关键变量（见下）。
- **核燃料**：铀资源对外依存度较高，国际铀价波动是成本端风险，但核电度电成本中燃料占比低（约10-15%），敏感度有限。

### 2.3 全球环保/碳市场对标

垃圾焚烧：欧洲（如瑞典、丹麦）垃圾焚烧供热发达且实现高能源化利用，但欧洲同时面临"垃圾不足"问题（回收率高+人口减少），中国当前"焚烧厂吃不饱"现象与欧洲后期困境类似，**行业从产能扩张转向运营效率+热电联产升级**。

碳市场：全国碳排放权交易市场已覆盖电力行业，碳价上升理论上利好零碳电源（水电、核电）的相对竞争力，但当前碳价对水电/核电直接收益传导有限（核电/水电多为保障性收购或市场化定价混合）。长期看，碳定价深化将提升低碳电源的绿电溢价空间。

## 三、产业链梳理、市场集中度与产能周期

### 3.1 水电产业链

```
上游：水轮机/发电机设备（东方电气、哈电集团、福伊特）+ 大坝工程（中国电建、中国能建/葛洲坝）
中游：水电站运营（长江电力、华能水电、国投电力、川投能源等）
下游：电网（国家电网/南方电网）→ 终端用户
```

**集中度**：极高。长江电力（600900）总装机约7170万千瓦（含溪洛渡、向家坝、乌东德、白鹤滩六座巨型电站），占全国水电装机的显著份额，是绝对龙头。华能水电（600025）主攻澜沧江流域，装机约2700万千瓦。两者合计占据全国大型水电的核心资产。

**产能周期**：水电是**产能不可复制的稀缺行业**。大型水电站资源已近开发完毕，新增500万千瓦以上电站近乎为零，意味着存量电站的"特许经营"价值随时间递增，无新增供给冲击。这是水电长期投资逻辑的基石。产能周期上，水电处于"存量价值释放期"而非"扩张期"。

### 3.2 核电产业链

```
上游：核燃料（中核国际、中核钛白等铀资源）+ 核级材料
中游：核岛设备（上海电气、东方电气、一重）+ 常规岛（哈电、东方电气）+ 工程建设（中国核建）
下游：核电运营（中国核电601985、中国广核003816，双寡头）
```

**集中度**：运营端为**双寡头格局**——中国核电（中核集团）与中国广核（中广核集团）合计占全国核电装机的绝大份额，华能集团小比例参股（国家能源局报告提及"华能首台"机组）。新进入者壁垒极高（牌照、安全、技术），集中度将持续。

**产能周期**：核电处于**明确的扩张投产周期**。2024年核准11台，连续3年超10台，"十五五"进入投产高峰。在建36台将陆续并网，装机规模持续增长。这是核电区别于水电（存量）的核心成长逻辑。但需注意：核电建设周期长（单台6-8年），资本开支前置、收益后置，投产期利润释放节奏是关键跟踪点。

### 3.3 环保（垃圾焚烧）产业链

```
上游：环卫/垃圾收运（地方环卫服务）
中游：垃圾焚烧发电运营（伟明环保、瀚蓝环境、光大环境、绿色动力等）
下游：电网购电（电费+国补）+ 地方政府垃圾处理费
```

**集中度**：分散度较高，区域性特征明显。伟明环保（603568）深耕浙江，瀚蓝环境（600323）主攻广东佛山，头部企业市占率有限但区域壁垒强。

**产能周期**：**明确进入产能过剩/出清周期**。央视《焦点访谈》报道"焚烧厂吃不饱"是标志性事件。前期各地一哄而上兴建焚烧厂导致处理能力过剩，叠加垃圾分类推进+人口结构变化使垃圾增量放缓，产能利用率下降。同时国补退坡（中央财政补贴逐步退出、转为地方承担）压制盈利。行业逻辑从"量增"转向"质升"（热电联产、运营效率、并购整合）。这是环保子行业当前最大的产能周期风险。

### 3.4 产能周期小结

| 子行业 | 产能周期 | 供给格局 | 投资含义 |
|---|---|---|---|
| 水电 | 存量稀缺，无新增 | 不可复制，集中度高 | 类债+稀缺溢价 |
| 核电 | 扩张投产期 | 双寡头，高壁垒 | 成长性，关注投产节奏 |
| 垃圾焚烧 | 产能过剩/出清 | 分散，区域化 | 规避扩张，关注整合能力 |

## 五、风险因素与多情景应对

### 5.1 核心风险因素

**(1) 来水风险（水电）**
水电盈利高度依赖来水。长江电力2022年净利下滑9.69%系来水偏枯所致。来水具有年际波动（丰枯交替），2026Q1长江电力+30.5%可能反映来水丰沛，但需警惕丰水年后转枯。华能水电（澜沧江流域）水文独立于长江，可分散部分来水风险。

**(2) 电价市场化/下行风险（核电+垃圾焚烧）**
核电参与市场化交易比例上升，若市场化电价低于上网标杆电价，将侵蚀利润——中国核电2024年净利-17.38%、2026Q1 -34.2%可能部分源于此（待核实具体原因）。垃圾焚烧电价含国补成分，国补退坡直接压减度电收入。

**(3) 利率回升风险（类债资产整体）**
若通胀超预期或货币政策转向收紧，无风险利率上行将压制水电/核电估值（久期长、敏感度高）。当前处于宽松预期中，但需跟踪CPI/利率拐点。

**(4) 防御溢价回吐风险**
板块近30日+9.61%已部分反映避险需求。若上证企稳反弹（融资余额13550亿回流已是信号），资金可能撤出防御板块追逐弹性，板块相对收益转负。

**(5) 产能过剩风险（垃圾焚烧）**
伟明环保2025净利-18%、2026H1 -35%已是产能过剩+国补退坡的直接体现。行业出清需时间，短期难逆转。

**(6) 核电安全/政策风险**
核电审批节奏受政策主导，若安全事件（虽概率极低）或审批放缓，将影响成长预期。当前审批连续3年超10台，节奏稳定。

**(7) 伟明环保创始家族减持风险**
2026年6月大宗交易集体减持，若持续减持将压制股价并影响治理信心。

### 5.2 多情景应对

**情景一：上证延续弱势/继续探底（防御占优延续）**
- 概率：中等偏高（已破MA250空头排列）
- 应对：超配防御核心仓，长江电力为压舱石（来水+股息+避险三重逻辑），核电配置成长弹性。伟明环保估值极低可小仓位左侧观察。
- 操作：长江电力逢回调加仓，中国核电PB低位分批布局。

**情景二：上证企稳反弹（防御溢价回吐）**
- 概率：中等（融资余额回流13550亿显示风险偏好修复迹象）
- 应对：减配纯防御标的（长江电力），保留核电（成长属性更强、受避险资金流出影响小）。伟明环保若业绩见底可博弈反转。
- 操作：长江电力获利了结部分仓位，核电视投产节点持有。

**情景三：利率超预期回升**
- 概率：低（当前宽松基调）
- 应对：减配长久期类债资产（水电首当其冲），核电因成长性可对冲部分久期风险。
- 操作：降低水电仓位，关注短久期或浮息特征资产。

**情景三（续）：来水转枯（水电盈利下滑）**
- 概率：中等（水文周期）
- 应对：长江电力业绩波动，但长期价值不变（来水均值回归）。华能水电（澜沧江）水文分散。
- 操作：逢业绩低点（来水枯年）反而加仓，博弈来水回归。
