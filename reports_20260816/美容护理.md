## 1. 行业概况与宏观相关性

### 1.1 行业规模与增长趋势

美容护理行业涵盖化妆品（护肤、彩妆、洗护）与医美（注射类、能量源、手术类）两大子赛道。中国化妆品零售总额在2024年约5000亿元规模（待核实，因行业统计口径差异），医美市场规模约3000-3500亿元（待核实）。2021-2023年为行业高增期，国货化妆品品牌增速普遍在20%-40%+，医美注射类龙头增速在30%-50%。但2024-2025年行业增速显著放缓，进入调整周期。

**2025年行业关键变化**：
- 国货化妆品龙头珀莱雅2025年营收首次负增长（-1.68%），主品牌首次出现负增长，标志着国货美妆高增时代结束
- 医美注射龙头爱美客2025年营收-18.94%、净利-34.05%，行业进入降价竞争阶段
- 华熙生物连续三年营收下滑（2023-2025分别-4.45%、-11.61%、-21.82%），原料端产能过剩压力显现
- 贝泰妮2025年营收-6.58%，但净利企稳（+0.53%），敏感肌赛道仍有韧性

### 1.2 与宏观经济的相关性分析

美容护理行业兼具"消费升级"与"消费降级"双重属性，其宏观相关性需要分赛道理解：

**化妆品（以珀莱雅、贝泰妮为代表）**：
- **消费力关联度高**：化妆品属于可选消费，与居民可支配收入正相关。2024-2025年居民消费意愿走弱，化妆品零售增速放缓。但国货品牌凭借性价比优势，在一定程度上受益于"消费降级中的消费分级"——消费者从国际大牌转向高性价比国货。
- **线上渠道依赖**：化妆品销售高度依赖电商（珀莱雅线上占比超80%），与平台流量成本、直播电商景气度强相关。流量红利消退是当前最大挑战。
- **当前宏观环境定位**：在上证跌破MA250（3927点）、防御板块占优的背景下，化妆品属于"弱防御性消费"——不如白酒/食品饮料防御性强，但好于周期品。国货替代逻辑提供了一定结构性增长机会。

**医美（以爱美客、华熙生物为代表）**：
- **消费升级关联度极高**：医美是典型的可选消费升级品类，与可支配收入预期强正相关。经济下行期，消费者倾向于推迟非必要医美消费或选择低价替代品。
- **渗透率仍低**：中国医美渗透率约3-5%（待核实），远低于韩国（20%+）、美国（15%+），长期空间仍在，但短期受消费信心拖累。
- **当前宏观环境定位**：医美在防御性板块中偏进攻，当前宏观环境下吸引力下降。爱美客2025年业绩大幅下滑已反映消费降级对高端医美的冲击。

### 1.3 政策环境

国务院"扩大消费十五五规划"为消费板块提供政策托底。化妆品新原料备案制度改革（2021年以来持续放宽）利好国货品牌研发创新。医美行业监管趋严（严打黑医美、规范注射类产品流通），利好合规龙头但短期可能抑制行业整体增速。

## 2. 国际维度与产业链格局

### 2.1 出口依赖度与海外收入占比

美容护理行业的国际维度因公司而异：

**华熙生物（688363）**：作为全球最大玻尿酸原料生产商，海外原料出口是其重要收入来源。2021年公司海外收入占比约30%（待核实最新数据）。玻尿酸原料出口面临国际竞争加剧（韩国KJ BIO、日本资生堂等），以及贸易环境不确定性。但原料业务在全球供应链中地位稳固，出口依赖度适中。

**珀莱雅（603605）**：2025年10月正式向港交所递交主板上市申请，拟成国内首家"A+H"股上市化妆品企业。公司面向日本、东南亚等市场加快出海步伐，但目前海外收入占比仍较低（预计<5%，待核实）。港股上市募资用途包括海外市场拓展和海外并购。

**爱美客（300896）**：医美注射产品以国内市场为主，海外收入占比极低。但公司在韩国设立子公司（Imeik Korea），布局韩国医美市场，国际化处于早期阶段。

**贝泰妮（300957）**：以国内市场为主，薇诺娜品牌在东南亚有一定布局，但海外收入占比微乎其微。

### 2.2 关税与贸易政策影响

- **原料端**：华熙生物的玻尿酸原料出口可能受关税影响，但玻尿酸作为工业原料关税通常较低。韩日原料竞争者可能在中美贸易摩擦中受益（若中国原料面临额外关税）。
- **品牌端**：化妆品进口关税持续下降（RCEP框架下），国际品牌进入中国成本降低，加剧国内竞争。但国货品牌凭借渠道和价格优势，仍占据主导。
- **医美产品**：进口医美注射产品（如艾尔建、Q-Med等）面临关税和注册审批双重壁垒，为国产品牌提供保护。

### 2.3 产业链上下游分析

**化妆品产业链**：
```
原料（华熙生物/帝斯曼/巴斯夫）
  → 研发配方（品牌方自研+代工厂ODM）
    → 生产（自建工厂/代工：科丝琪诗/诺斯贝尔）
      → 品牌（珀莱雅/贝泰妮/彩棠等）
        → 渠道（天猫/抖音/京东/线下CS/百货）
          → 终端消费者
```

- **上游原料**：华熙生物是玻尿酸原料龙头，但在合成生物学、多肽、植物提取物等新原料领域，国际巨头（帝斯曼、巴斯夫、赢创）仍占主导。中国新原料备案制度改革后，国货品牌自研原料能力提升。
- **中游生产**：化妆品代工集中度低，头部代工厂科丝琪诗、诺斯贝尔等议价能力有限，品牌方掌握产业链主导权。珀莱雅自建杭州工厂，提升自主生产能力。
- **下游渠道**：线上渠道占比持续提升（珀莱雅线上占比超80%），但流量成本高企成为核心痛点。珀莱雅2025年前三季度销售费用率高达49.66%，研发费用率仅约2%。

**医美产业链**：
```
原料（华熙生物玻尿酸/胶原蛋白原料）
  → 研发生产（爱美客/华熙生物/昊海生科）
    → NMPA注册审批（III类医疗器械，周期3-5年）
      → 机构（公立医院/连锁机构：美年/美莱/艺星）
        → 医生注射
          → 终端消费者
```

- **上游原料**：玻尿酸原料产能过剩（华熙生物、焦点生物等扩产），原料价格持续下行。胶原蛋白原料（重组胶原蛋白）成为新热点。
- **中游生产**：爱美客专注于终端注射产品，毛利率高达92.7%，是产业链中最具价值环节。NMPA III类医疗器械注册证构成高壁垒。
- **下游机构**：医美机构分散，连锁化率低，获客成本高企。机构端利润率远低于产品端，爱美客作为产品方议价能力强。

## 3. 市场集中度与产能周期

### 3.1 市场集中度

**化妆品国货品牌**：
- 国货化妆品CR5约15-20%（待核实），集中度较低，但国货品牌份额持续提升。2023年珀莱雅超越上海家化成为国货美妆营收第一。
- 护肤品赛道：国货品牌（珀莱雅、贝泰妮/薇诺娜、自然堂、百雀羚）vs国际品牌（欧莱雅、雅诗兰黛、兰蔻）。国货在大众护肤占比提升，高端市场仍被国际品牌主导。
- 敏感肌赛道：贝泰妮/薇诺娜在敏感肌细分赛道国货市占率领先，但面临理肤泉（欧莱雅）、薇姿等国际品牌竞争加剧。

**医美注射类**：
- 透明质酸填充剂：爱美客（嗨体、逸美一加一）市占率国内领先，竞争对手包括华熙生物（润百颜）、昊海生科（海薇）、韩国LG（伊婉）、瑞典Q-Med（瑞蓝）。爱美客在嗨体（颈纹修复）细分市场接近垄断。
- 重组胶原蛋白：巨子生物、锦波生物等新进入者，成为玻尿酸替代品，竞争加剧。
- 肉毒素：兰州生物（衡力）、艾尔建（保妥适）双寡头格局，爱美客布局肉毒素在研产品。

### 3.2 产能周期位置

**玻尿酸原料产能过剩**：
- 华熙生物作为全球最大玻尿酸原料商，2022-2025年营收连续下滑（63.59亿→41.99亿），核心原因之一是原料端产能过剩导致价格下行。
- 焦点生物、阜丰生物等竞争对手扩产，叠加韩国KJ BIO竞争，原料价格持续承压。
- 华熙生物正在从原料向终端产品转型，但终端产品竞争同样激烈（医美注射、功能性护肤品、功能性食品）。
- **判断：玻尿酸原料处于产能过剩去化阶段，预计还需1-2年出清。**

**医美渗透率阶段**：
- 中国医美渗透率约3-5%（待核实），远低于韩国（20%+）、美国（15%+），长期渗透率提升空间大。
- 但短期受消费降级影响，医美消费频次下降、客单价下行。爱美客2025年营收-18.94%反映了这一短期冲击。
- 嗨体（爱美客核心产品）2025年增长放缓，可能与竞品进入和消费降级双重因素有关。
- **判断：医美处于渗透率长期提升但短期调整的阶段，2025-2026年为行业底部区域。**

### 3.3 竞争格局变化（2026年趋势）

- **国货vs国际品牌**：国货品牌在大众市场持续替代国际品牌，但在高端市场突破有限。珀莱雅大单品策略（红宝石精华、双抗精华）成功抢占心智，但增长天花板显现。
- **新原料竞争**：重组胶原蛋白成为玻尿酸之后的新热点，锦波生物、巨子生物等新玩家进入，对爱美客和华熙生物构成跨界竞争。
- **渠道变革**：直播电商红利消退，抖音渠道增速放缓，品牌获客成本持续攀升。珀莱雅销售费用率近50%，反映渠道成本压力巨大。

## 6. 风险因素与结论

### 6.1 主要风险

1. **消费降级持续**：2024-2025年美容护理行业全面放缓，化妆品和医美均为可选消费，经济下行期消费者减少支出或选择低价替代品。爱美客2025年营收-18.94%已反映高端医美受冲击。

2. **竞争加剧**：重组胶原蛋白（锦波生物、巨子生物）对玻尿酸注射产品形成替代；化妆品赛道新品牌不断涌现，珀莱雅大单品策略面临模仿竞争。

3. **渠道成本上升**：珀莱雅销售费用率近50%，直播电商红利消退，获客成本持续攀升，侵蚀利润空间。

4. **监管收紧**：医美行业监管趋严（严打黑医美、广告限制），短期可能抑制行业增速。化妆品新规（功效评价、原料安全）增加合规成本。

5. **原料产能过剩**：华熙生物玻尿酸原料面临产能过剩和价格下行压力，转型终端产品过程中竞争激烈。

6. **大股东减持**：华熙生物（国寿成达、华熙昕宇）、贝泰妮（红杉资本）大股东持续减持，形成股价压制。

7. **业绩底部不确定**：爱美客Q1 2026继续-32.79%、华熙生物Q1 2026继续-36.55%，底部尚未明确。
