### 1.2 行业景气度核心判断

**ADC赛道：2026年进入黄金兑现期。** 据摩熵医药《ADC药物研发与市场全景研究报告》（2026.05发布）：
- 全球ADC管线达**406条**（I期188 / II期145 / III期48 / 申请上市6 / 已上市19），研发热度爆发
- 中国企业占全球TOP10管线企业**5席**（宜联生物、信达生物、多禧生物、百利天恒等），从跟随到领跑
- 国内ADC市场规模2025年达**62.2亿元**，4年间从6.1亿扩容超10倍，CAGR约78%
- 院外市场（零售药店24.8亿，39.8%）增速超院内，可及性提升

**License-out/BD交易：中国biotech出海加速。** 2026年标志性BD交易频出：
- 百利天恒：BL-B01D1（全球首个EGFR×HER3双抗ADC）与BMS达成**84亿美元**合作（2024年确认首付款，2025年回归亏损）
- 荣昌生物：**2026H1盈利约47亿元**（营收58.5亿/+433%），利润率80%，几乎确定含大额BD授权首付款（具体交易细节待核实正式公告）
- 科伦博泰：ADC管线授权默沙东（已知大额交易）

**扭亏拐点：头部biotech进入商业化兑现期。**
- 百济神州：2025年营收382.25亿（+40%），**首次归母净利14.61亿扭亏**，扣非14.20亿（真经营盈利），OCF 8.90元/股
- 荣昌生物：2025年扭亏（净利7.10亿，但扣非仅6767万），2026H1再爆发（盈利47亿）

**行业景气度判断：★★★★（高景气）。** ADC高景气+BD出海兑现+扭亏拐点三重逻辑共振，但宏观进攻弱势+估值偏高构成短期压制。

## 2. 竞争格局

### 2.1 (a) 国际维度：海外biotech对标 / License-out / 全球管线

**海外biotech对标：**
- 第一三共（DXd平台）：全球ADC技术标杆，Enhertu（德曲妥珠单抗）2025年国内销售23.2亿元领跑
- 辉瑞：全球ADC管线数量第一，收购Seagen后整合
- 罗氏/阿斯利康：聚焦前沿靶点，与本土企业协同竞争

**License-out/全球管线授权（重点）：**
| 标的 | BD交易 | 金额 | 状态 |
|---|---|---|---|
| 百利天恒 | BL-B01D1授权BMS | 84亿美元 | 2024年确认首付款，全球III期推进中 |
| 荣昌生物 | 2026H1盈利47亿（疑似BD大单） | 待核实 | 8月5日预告披露 |
| 科伦博泰 | ADC授权默沙东 | 超百亿美元级 | 已知大额交易 |
| 百济神州 | 泽布替尼全球自主商业化 | 营收382亿（2025） | 已在美国/欧洲/日本获批销售 |

**国际化判断**：中国biotech已从"License-in引进"全面转向"License-out出海"，ADC是中国创新药全球竞争力最强的细分赛道。BD交易首付款成为亏损biotech的关键现金来源，但需警惕**一次性收入不可持续**的利润质量风险。

### 2.2 (b) 产业链图谱

```
上游（试剂/耗材/CDMO）          中游（biotech研发）           下游（临床/商业化）
├─ 试剂：培养基/抗体/毒素载荷    ├─ 靶点发现/抗体筛选          ├─ CRO临床（药明康德/泰格）
├─ 耗材：一次性反应器/填料       ├─ ADC偶联技术平台             ├─ 商业化生产（GMP产能）
├─ CDMO：药明生物/凯莱英        ├─ 临床前研究/IND申报          ├─ 院内销售（处方驱动）
│  （偶联工艺/产能外包）         ├─ I-III期临床推进             ├─ 院外/DTP药房（零售放量）
└─ 毒素/连接子：MMAE/DXd等      └─ NDA/商业化                  └─ 医保/基药准入
```

**上游议价力**：ADC毒素载荷（MMAE、DXd、拓扑异构酶抑制剂）和定点偶联技术是核心瓶颈，掌握自主平台的企业（百利天恒、荣昌生物）议价力强。CDMO（药明生物）承担偶联工艺外包，产能扩张中。

**下游渠道变化**：ADC院外市场（39.8%）快速崛起，DTP药房和双通道政策提升可及性。纳入基药/医保目录是关键放量催化剂（荣昌生物泰它西普2026年7月纳入基药目录）。

### 2.3 (c) 行业集中度 CR3 / CR5

**ADC市场集中度（2025年国内62.2亿元）：**
- TOP10品种合计占市场**>95%**，高度集中
- CR3（品种）：德曲妥珠单抗23.2亿 + 维迪西妥单抗11.7亿 + 维泊妥珠单抗11.7亿 ≈ 46.6亿，CR3 ≈ **75%**
- 企业梯队：第一梯队（科伦博泰、荣昌生物、百利天恒、恒瑞）+ 第二梯队（石药、信达、多禧、宜联、映恩）

**创新药biotech整体集中度**：行业整体分散（数百家biotech），但头部企业集中度持续提升。2025年ADC申报注册TOP3企业（恒瑞39件+百利天恒25件+科伦9件）占比显著。百济神州以382亿营收遥遥领先，是唯一进入全球销售级别的中国biotech。

### 2.4 (d) 产能周期：管线推进 / 商业化产能

| 标的 | 管线阶段 | 商业化产能 | 产能周期判断 |
|---|---|---|---|
| 百济神州 | 泽布替尼全球商业化，百泽安（PD-1）国内销售 | 全球供应链已验证，产能充足 | **商业化成熟期**，产能利用率高 |
| 荣昌生物 | 泰它西普（已上市）+维迪西妥单抗（已上市），8条临床管线 | 烟台生产基地，纳入基药后需求释放 | **产能扩张期**，基药准入驱动产能爬坡 |
| 百利天恒 | BL-B01D1全球III期，多款ADC早期临床 | 商业化产能建设中 | **产能建设期**，尚未大规模商业化 |
| 信达生物 | 信迪利单抗（已上市）+玛仕度肽（NDA）+ADC管线 | 已有商业化产能 | **产能扩张期**，GLP-1若获批需新建产能 |

**产能周期结论**：ADC偶联工艺产能是行业瓶颈，CDMO（药明生物）和自建产能（荣昌生物烟台基地）同步扩张。管线推进到III期/商业化阶段的企业（百济、荣昌）产能利用率高，早期企业（百利天恒）仍需投入。
