## 一、行业现状与趋势（研报视角）

### 1.1 行业总体规模

| 指标 | 2024年 | 2025年实际/确认 | 2026年展望 |
|------|--------|---------------|-----------|
| 中国家电市场规模 | ~8,800-9,000亿元 | ~9,500亿元（以旧换新拉动约15%增长） | ~10,000亿元+ |
| 全球家电市场中国占比 | 30-35% | 持续提升至35%+ | 预计35%+ |
| 中国家电出口总额 | ~850亿美元(+12%) | ~920-950亿美元(+8-10%) | ~1,000亿美元 |
| 智能家居设备渗透率 | ~35-40% | ~45%(IDC确认) | ~50%+ |
| AI家电新品占比 | ~25-30% | ~40%(三大龙头确认) | ~50%+ |
| 扫地机器人渗透率 | ~6-8% | ~8-10%(奥维云网数据) | ~12-15% |
| Matter认证产品数 | ~1,200款(2024底) | 大幅增长，50+中国厂商Thread认证 | 2026年5亿+台/年 |

**市场结构（2025年预计）**：

- 白电（空调/冰箱/洗衣机）：~4,350亿元，占46%
- 小家电（厨房/个护/清洁）：~2,630亿元，占28%，增速最快（10-15% CAGR）
- 黑电及其他：~2,520亿元，占26%

### 1.2 白电：龙头稳固，防御属性突出

| 白电品类 | 2024年规模 | 2025年预计 | 关键趋势 |
|----------|-----------|-----------|---------|
| 空调 | ~2,200亿元 | ~2,400亿元 | 内销+出口双驱动 |
| 冰箱 | ~1,000亿元 | ~1,100亿元 | 高端多门增速快 |
| 洗衣机 | ~800亿元 | ~850亿元 | 洗烘一体增长明显 |

- **行业集中度高**：格力、美的、海尔三大品牌白电合计市占率超60%
- **出口强势**：空调出口量全球占比约70%；冰箱约50%
- **白电出口增速**：2025年预计维持5-8%增速

### 1.3 小家电：增速最快，创新驱动

| 小家电品类 | 2024年规模 | 2025年预计 | 增速 |
|-----------|-----------|-----------|-----|
| 厨房小家电 | ~1,200亿元 | ~1,350亿元 | ~12% |
| 个人护理小家电 | ~600亿元 | ~700亿元 | ~15% |
| 环境清洁小家电 | ~500亿元 | ~580亿元 | ~16% |

- 空气炸锅、扫地机器人、高速吹风机等新品类增长突出
- 小家电出口额约占中国家电出口总额25-30%
- 跨境电商（亚马逊、Temu等）成为小家电出口新渠道，增速超30%

### 1.4 出海战略：从代工到品牌

中国家电全球化正经历从OEM -> ODM -> 自有品牌的转型：

- 2024年家电出口额同比+12%，预计2025-2026年保持8-10%增速
- 海尔、美的海外自有品牌收入占比已提升至30-40%
- 全球家电出口份额中，中国占40-45%
- 出海目的地正从欧美向东南亚、中东、拉美加速转移（受地缘政治和关税影响）
- 小家电多品类全球出口占比50-60%

### 1.5 以旧换新政策红利

- 2024年以旧换新补贴效果显著，拉动零售额增长约15%
- 预计拉动白电/厨电换新需求约2,000亿元规模
- 2025年政策延续且范围扩大，新增覆盖小家电、清洁电器等品类
- 2026年政策效应可能递减，消费复苏需依赖内生动力

### 1.6 核心趋势研判（2025-2026）

| 维度 | 2025年 | 2026年 |
|------|--------|--------|
| 内需 | 以旧换新政策驱动，温和复苏 | 政策效应递减，依赖消费内生动力 |
| 出海 | 增速8-10%，品牌化加速 | 全球份额继续提升，区域性风险增加 |
| 技术 | AI+家电初步融合 | 智能场景渗透率显著提升（30%+） |
| 格局 | 龙头集中度进一步提高 | 结构性升级为主，高端化趋势明确 |
| 投资主线 | 白电龙头+政策受益 | 白电守底+小家电/清洁电器博成长 |

### 1.7 各券商核心观点

- **中金公司**：内需复苏与出海双驱动，关注白电龙头估值修复及小家电细分赛道成长性
- **申万宏源**：以旧换新拉动约2,000亿元换新需求，首推白电龙头（稳定现金流+高分红），关注清洁电器渗透率提升逻辑
- **华泰证券**：2026年结构性机会为主，高端化、智能化、绿色化三大主线；"稳"选白电龙头、"成长"选小家电/清洁电器、"弹性"选厨电
- **招商证券**：中国家电出海从代工到品牌的新阶段，优先关注已建立海外品牌认知和渠道壁垒的龙头企业
- **东方证券**：政策受益标的优先，重点关注渠道布局完善、品牌力强的龙头

## 二、创新与技术突破（SOTA视角）

### 2.1 智能家居互联协议：Matter/Thread成为主流

**现状与趋势**：

- Matter认证产品已超过1,200款（截至2024年底），预计2025-2026大幅增长
- Thread Border Router已内置到Apple HomePod、Google Nest Hub、Amazon Echo等主流设备
- Thread设备出货量预计2026年达5亿+台/年
- Matter/Thread智能家居市场CAGR预计25-30%

**关键进展**：

- Whirlpool、Miele、Bosch、LG等大型家电制造商已宣布Matter集成计划
- Matter协议2025年更新增强能源管理功能，支持跨设备能效协调
- 主要障碍：大型家电10-15年替换周期，Matter认证流程复杂

**全球智能家居市场规模**：预计2026年达180-200亿美元，Matter/Thread将成为新设备主流连接标准。

### 2.2 Edge AI与TinyML：家电端侧智能

**核心突破**：

- **神经形态处理器**：专为家用机器人开发的低功耗AI芯片，能耗比传统AI芯片降低100倍
- **端侧推理**：语音助手、智能恒温器、扫地机器人等可在设备本地运行AI模型，无需云端连接
- **斯坦福HAI研究**："Embodied AI for Sustainable Homes"，家用机器人围绕可持续性原则设计，实地试验显示平均22%能耗降低

**应用场景**：

| 应用 | Edge AI功能 | 效果 |
|------|------------|------|
| 智能恒温器 | 学习用户习惯，预测调节 | 能耗降低20-30% |
| 扫地机器人 | 本地路径规划+物体识别 | 无需云端，隐私更好 |
| 语音助手 | 本地唤醒+命令理解 | 响应更快，离线可用 |
| 智能冰箱 | 食物识别+用量预测 | 减少浪费，优化采购 |

### 2.3 AI优化能效：节能突破

**关键数据**：

- **美国能源部（DOE）报告**：AI集成家电（包括机器人清洁器、智能HVAC、AI冰箱）若大规模部署，可降低住宅能耗25%（2026预测）
- **强化学习突破**：用于家电能源调度的新RL算法，可学习使用模式并实时调整运行
- **三星Ballie与LG智能家庭机器人**：CES 2025/2026展示"能效感知"模式，实时监测家庭能耗，自动关闭闲置设备，优化供暖/制冷，LG声称可降低家庭能源账单15-20%

**监管动向**：

- 欧盟计划为AI驱动的家电和机器人更新能效标签法规，要求AI系统自身能耗透明化
- 确保AI处理开销不会抵消家电效率增益

### 2.4 具身智能与LLM驱动的智能家居编排

**研究前沿**：

- **LLM作为家居编排中枢**：接收高层用户意图（如"准备晚餐招待客人"），分解为子任务（设置灯光、预热烤箱、铺设餐桌、清扫客厅），调度各子代理执行

  - SayCan-Home：将SayCan扩展到全家居编排场景

  - NVIDIA EMBER：具身多代理基准，家用多机器人协作

### 2.5 数字孪生与预测性维护

数字孪生技术在家电领域正从工业级应用向消费级渗透。核心场景包括：

**技术架构**：通过IoT传感器采集设备运行数据（温度、振动、能耗模式），在云端建立虚拟副本实时同步，利用ML算法识别异常模式并预测故障。应用于HVAC系统、洗衣机、冰箱等长寿命家电。

**商业价值**：
- 降低大型家电维修成本30-40%，延长使用寿命2-3年
- 从"被动维修"转向"主动预防"，提升用户满意度和服务收入
- 海尔智家"三翼鸟"方案已集成数字孪生模块，用于全屋智能设备生命周期管理
- 美的"美居"平台通过设备数据建模优化维保调度

**2025-2026进展**：arxiv综述(2025.08)系统梳理了数字孪生在家电IoT的框架，从实时模拟到预测性维护形成完整方法论。Gartner预测2026年超30%的大型家电品牌将提供基于数字孪生的增值服务订阅。

### 2.6 清洁电器/扫地机器人技术前沿

扫地机器人正从"清扫工具"向"家庭智能代理"演进，这是AI家电领域最具标志性的产品形态迭代。

**技术升级路线**：
- **3D避障+AI物体识别**：从早期随机碰撞到激光雷达SLAM，再到2025年主流的3D结构光+RGB摄像头融合避障，识别电线、拖鞋、宠物粪便等细小障碍物
- **自清洁基站**：2025年"扫拖洗+自清洁基站"成为旗舰标配，代表产品石头G20S、科沃斯X2 Pro，实现全流程无人干预
- **LLM+VLM赋能自然语言指令**：用户可通过语音下达"清扫厨房桌底"、"避开宠物区域"等语义指令，石头科技2025年新品已集成LLM理解能力
- **多楼层地图记忆**：支持3-5层独立地图，自动识别楼层切换

**市场格局**：中国品牌（科沃斯、石头科技、追觅）在全球扫地机器人市场份额约80%+，出口额超40亿美元。2025年中国市场渗透率约8-10%（奥维云网），远低于美国15%+，增长空间巨大。石头科技份额约25%领先，追觅约20%快速追赶，科沃斯约18%稳守。

**下一代演进方向**：从清洁工具升级为家庭智能代理——集成环境感知、安防巡检、物品搬运等多功能，与LLM家居编排中枢对接，实现"清扫厨房+整理桌面+关闭闲置灯光"等复合指令。

## 三、投资建议

### 3.1 核心投资主线

**主线一：白电龙头——"稳"的选择**

- 代表标的：美的集团、海尔智家、格力电器
- 核心逻辑：高分红（股息率3-5%）+稳定现金流+估值偏低+以旧换新政策受益
- 2026年判断：防御属性强，业绩确定性高，但增长弹性有限
- 关注点：海外自有品牌占比提升进度、AI家电产品落地节奏

**主线二：小家电/清洁电器——"成长"的选择**

- 代表标的：科沃斯、石头科技、苏泊尔、新宝股份
- 核心逻辑：渗透率低（中国扫地机器人渗透率约5-8%，对标日本/欧美15-20%）、成长空间大、新品类持续涌现
- 2026年判断：增速远超白电（10-15% CAGR），但竞争格局变化需密切关注
- 关注点：海外市场拓展进度、技术迭代速度（AI+3D避障+自清洁）

**主线三：厨电龙头——"弹性"的选择**

- 代表标的：老板电器、华帝股份
- 核心逻辑：地产后周期受益，若地产政策进一步放松则具备弹性空间
- 2026年判断：弹性品种，需跟踪地产数据和政策风向
- 关注点：以旧换新政策覆盖范围扩大是否纳入厨电

### 3.2 主题性投资机会

**主题一：智能家居/AI家电**

- Matter/Thread协议普及将推动智能家居生态加速整合
- LLM驱动的家居编排（从规则式到认知式）有望成为下一代智能家居范式
- 关注具备AI/物联网技术积累的龙头（海尔智家三翼鸟全屋智能、美的美居平台）

**主题二：家电出海品牌化**

- 从OEM代工到自有品牌出海是未来3-5年核心趋势
- 优先关注已建立海外品牌认知和渠道壁垒的企业（海尔北美GE品牌、美的东芝品牌）
- 跨境电商渠道带来小家电出海新机遇（新宝股份等）

**主题三：绿色节能/碳中和**

- 新能效标准持续推动产品升级换代
- AI优化能效技术有望成为产品差异化卖点
- 欧盟能效标签更新将影响出口产品标准，提前布局的企业受益

**主题四：具身智能/家用机器人**

- 2025-2026年是家用机器人从实验室到消费市场的关键过渡期
- Samsung Ballie、Amazon Astro等产品计划2025-2026年上市
- 扫地机器人率先受益于具身AI技术溢出，有望从清洁工具升级为家庭智能代理
- 但消费级家用通用机器人大规模商业化仍需2-3年以上

| 风险类别 | 具体内容 | 影响评估 |

| 原材料价格波动 | 铜/铝/钢/塑料等大宗商品价格波动 | 中-高，直接影响毛利率 |
| 海外贸易壁垒 | 关税提升/反倾销/地缘政治风险 | 高，出海核心风险 |
| 国内消费复苏不及预期 | 以旧换新政策效应递减+居民消费意愿弱 | 中-高，影响内需增长 |
| AI家电落地节奏不确定 | 技术成熟度+消费者接受度+生态碎片化 | 中，长期逻辑但短期兑现难 |
| 行业竞争加剧 | 小家电/清洁电器赛道竞争格局恶化 | 中，影响利润率 |
| AI自身能耗问题 | AI处理开销可能抵消家电效率增益 | 低-中，监管关注但影响有限 |

## 五、跨行业关联

| 关联行业 | 关联逻辑 | 影响方向 |
|----------|---------|---------|
| **房地产** | 新房交付+装修驱动家电换新需求 | 房地产→家电（需求拉动） |
| **有色金属** | 铜/铝是家电核心原材料 | 有色→家电（成本端） |
| **化学化工** | 塑料树脂/制冷剂是家电关键化工材料 | 化工→家电（材料供给） |
| **电子半导体** | MCU/传感器/WiFi芯片是智能家电核心 | 半导体→家电（零部件） |
| **轻工制造** | 家居配套(海尔三翼鸟)是家电+轻工交集 | 家电↔轻工（整家方案） |
| **人工智能** | AI家电/家用机器人是AI+家电前沿 | AI→家电（智能化） |

> **跨行业投资启示**：家电受以旧换新政策(需求端)+出海全球化(增长端)+AI智能化(升级端)三线驱动，白电稳健+以旧换新是核心配置。
