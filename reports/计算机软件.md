## 一、行业现状与趋势（研报视角）

### 1.1 全球软件与云服务市场

**市场规模与增速**（来源：Gartner、IDC）：

| 指标 | 2024年(实际确认) | 2025年(实际/最新进展) | 2026年展望 |
|------|------------------|----------------------|-----------|
| 全球公有云市场 | $723.4B(确认) | ~$805-850B(Gartner/IDC) | ~$880B-$1T |
| SaaS细分 | ~$284B | ~$300-320B | ~$340B+ |
| IaaS细分 | ~$194B | ~$210-220B | ~$250B+ |
| PaaS细分 | ~$108B | ~$120-130B | ~$140B+ |
| SaaS占比 | ~39% | ~38-40% | ~38-40% |
| 整体增速 | ~21.5% | ~17-19% | ~18-20% |
| SaaS CAGR(2024–2028) | ~17% | ~14-16%(修正) | — |

**核心趋势**：
- **SaaS成为主流交付模式**：Forrester预测2026年SaaS将成为占主导地位的软件消费模型，企业SaaS采用率超过95%。
- **AI集成SaaS（AIaaS）**：AI Copilot、智能自动化嵌入SaaS产品是增速最快的细分方向，McKinsey估算AI可为云/SaaS行业额外创造$1.5–3.3万亿经济价值。
- **多云/混合云成为企业标准架构**：企业级多云策略占比持续提升，云原生安全（SASE、零信任）为优先投资领域。
- **Vertical SaaS**：行业垂直SaaS（金融、医疗、制造）加速渗透，增长快于通用SaaS。
- **亚太区增速最高**：中国、印度、东南亚云/SaaS增速领先全球。

### 1.2 中国计算机软件行业

**三大投资主线**（多家券商共识：中信证券、华泰证券、海通证券、国信证券）：

#### 主线一：AI商业化落地

- 2025年被视为AI大模型从"概念验证"走向"规模化部署"的关键年，2026年预计为AI应用真正放量之年。
- AI Agent、RAG（检索增强生成）等新范式催生软件新需求，金融、医疗、政务、教育为首批规模化应用场景。
- 代表标的：科大讯飞、金山办公、软通动力。

#### 主线二：信创/国产替代

**政策关键节点**：
- 2027年为党政及关键行业信创替代Deadline，2025–2026是替代加速的关键窗口期。
- "2+8+N"体系（党政→八大行业→更多领域）从规划进入规模化落地期。
- 2025年多地要求党政信创阶段性验收，核心环节替代率需达50%–80%。

#### 主线三：数据要素市场化

- 国家数据局2023年10月成立，统筹全国数据政策。

### 1.3 行业风险提示

- 宏观经济复苏不及预期影响IT支出
- AI商业化进度慢于预期（落地节奏不确定）
- 信创订单释放节奏存在不确定性
- 板块估值仍偏高，需关注业绩兑现能力
- 国产软件生态适配仍落后于海外产品，迁移成本高
- 国产DB在高端场景（金融核心交易）性能仍与Oracle有差距

### 2.2 自主编程Agent：范式转换

**SWE-bench Verified排行榜**（500个经人工验证的真实GitHub Issue）：

| Agent系统 | SWE-bench Verified 解决率 | 说明 |
|----------|------------------------|------|
| OpenDevin/OpenHands + Claude 3.5 Sonnet | ~53% | 最高报告之一 |
| Amazon Q Developer Agent | ~53% | 与OpenHands持平 |
| SWE-agent + Claude 3.5 Sonnet | ~33–50% | 取决于配置 |
| Codex（OpenAI） | ~36% | OpenAI官方Agent |
| Devin（Cognition） | ~13–25% | 早期结果，全自主模式 |

**技术突破要点**：
- 2025年AI编程Agent已能端到端解决真实GitHub Issue：读取Issue描述、导航陌生代码库、定位根因、实现修复、运行测试验证。
- 从"Copilot（辅助补全）"走向"Autopilot（自主执行）"的范式转换：Agent可规划、执行、审查多步骤开发工作流。
- 代表工具：Devin（Cognition）、Claude Code（Anthropic）、Amazon CodeWhisperer Agent、OpenHands。

**企业级采纳进展**：
- Google、Microsoft、Meta等已开始内部部署自主编程Agent处理生产级工作负载。
- Agent被分配真实Jira Ticket，编写生产级代码并通过Code Review（关键系统仍有人类监督）。
- GitHub Copilot付费订阅用户2025年初已达180万+。
- Gartner/IDC预测2025–2026年70–80%大型企业将采纳某种形式的AI编程辅助工具。

**开发者生产力实证**：
- GitHub研究+McKinsey报告：使用Copilot的开发者在特定编码任务中完成速度提高55%。
- 74%开发者报告可专注更有满足感的工作，87%感到更高效。
- 注意：55%提升为任务级指标，不等同于项目级或组织级生产力整体提升（架构决策、调试、会议、Code Review等环节加速不均）。

### 2.3 前沿方向与开放挑战

**新兴方向**：
- **AI原生开发（AI-native development）**：软件从设计之初就考虑由AI Agent构建和维护，代码成为"可由AI读写和修改的文档"，而非纯粹的人类指令。2025-2026年这一理念从学术讨论走向初步实践，代表性项目包括GitHub Copilot Workspace和Cursor的Agent模式。
- **Repository级理解**：超越单函数生成，走向多文件、项目级推理。关键技术包括：上下文缓存优化（支持100K+ token的代码库理解）、AST-based代码导航（自动定位跨文件依赖）、语义搜索（在代码库中快速定位相关模块）。DeepSeek-Coder和Claude Code在此方向上持续突破。
- **Agent参与团队协作**：2025年已出现Agent参与Code Review、自动修复CI失败、编写测试的案例。预测2026年AI Agent将从工具进化为"团队成员"，参与Sprint规划、架构讨论和Code Review。GitHub Copilot Autofix（2025年推出）已实现自动检测并修复安全漏洞。
- **多模态代码生成**：从UI截图/设计稿直接生成前端代码。2025年代表性工具包括：v0.dev（Vercel，从截图生成React组件）、Screenshot-to-Code（开源项目，支持多种前端框架）、Claude Artifacts（从描述生成完整前端应用）。
- **2026年预测**：自主AI编程Agent将处理企业环境中40-60%的常规开发任务。大型企业的软件开发流程将系统性集成AI Agent，从需求分析、代码编写、测试到部署的全链条自动化比例持续提升。

**开放挑战**：
- **幻觉与安全**：AI生成代码存在安全漏洞（OWASP AI Top 10风险清单）、虚构依赖（引用不存在的包/函数）等问题，需健壮的验证框架。2025年GitHub Copilot Autofix和Snyk AI等工具开始针对性解决此问题。
- **上下文长度限制**：大型代码库的完整理解仍受模型上下文窗口制约。Gemini 1.5 Pro的1M token上下文、Claude 3.5的200K token上下文提供了更大窗口，但企业级百万行代码库的理解仍需分层/摘要/检索策略辅助。
- **架构决策**：Agent在新型架构决策和高度领域特定的业务逻辑上仍有困难。SWE-bench数据显示Agent擅长修复Bug和小规模重构，但大型架构升级和多模块协调能力仍远不及人类高级工程师。
- **企业采纳差距**：Benchmark性能与真实世界效用之间存在落差。关键障碍包括：代码质量合规（企业代码规范、安全审计）、知识产权赔偿（AI生成代码的版权归属）、组织变革阻力（开发者对AI工具的信任建立需要时间）。

### 3.2 细分赛道投资建议

**AI+软件**：
- 关注已落地AI产品并有商业化营收的公司，而非纯概念标的。
- 重点观察AI Agent在垂直行业的渗透率指标（金融、政务优先）。
- 金山办公（WPS AI功能嵌入）、科大讯飞（大模型+行业应用）为典型代表。

**信创**：
- 操作系统：麒麟+统信格局稳定，关注openEuler服务器端替代加速。
- 数据库：达梦在党政领域替代率最高，金融领域关注GaussDB、TDSQL、OceanBase。
- 整体信创订单节奏需跟踪政府采购季度数据，2025H2–2026为订单密集期。

**工业软件/EDA**：
- 高壁垒长赛道，国产化率极低（EDA国产化率<5%），政策+国产替代双驱动。
- 华大九天（EDA模拟电路工具）、中望软件（CAD/CAE）、概伦电子（EDA器件建模）为代表。
- 估值偏高但成长确定性强，适合长线配置。

**网络安全**：
- 合规驱动（数据安全法、关基保护条例），需求刚性。
- 奇安信、深信服、安恒信息为头部标的，关注AI安全新方向。

**云计算/SaaS**：
- 全球SaaS 2025年市场规模~$284B，CAGR 12–17%。
- 中国SaaS渗透率仍低于全球，AI赋能云化升级（用友、金蝶）为中期逻辑。
- 重点关注AI Copilot嵌入SaaS产品的进展。

### 3.3 风险对冲建议

- 板块整体估值偏高，建议分批建仓，避免追高。
- 信创标的需跟踪季度订单数据验证，防止"预期提前、订单滞后"的估值陷阱。
- AI商业化进度存在不确定性，优先选择已验证营收兑现的标的。
- 海外AI编程Agent技术突破可能对国内传统外包型软件公司形成替代压力，需关注结构性风险。
