# 纺织服装 投资研究报告

> 撰写日期：2026年6月16日 | 数据截至：2025年中期及可获取的最新公开信息

---

## 一、行业现状与趋势（研报视角）

### 1.1 全球市场规模与增长

- 全球纺织市场规模约**1.0-1.1万亿美元**，预计以CAGR **4.0-4.5%**增长至2026-2030年。
- 全球时尚服饰产业规模预计2026年达到**1.7-2万亿美元**，服装为最大细分。
- 无缝/3D针织服装细分市场预计2026年达到**58亿美元**（GlobalData预估）。
- 再生纤维目前仅占全球纤维产量约**1%**（Textile Exchange），增长空间巨大。

### 1.2 中国纺织服装出口数据

| 指标 | 2024年全年 | 2025年全年(截至可获取) |
|------|-----------|-------------|
| 纺织服装出口总额 | ~2,715亿美元，同比+1.5% | 预计~2,800-2,850亿美元，同比+3-5%，增速温和回升 |
| 纺织品出口 | ~1,440亿美元 | 预计~1,480-1,500亿美元 |
| 服装出口 | ~1,275亿美元 | 预计~1,320-1,350亿美元 |

**出口结构性变化**：
- 对东盟出口增速较快（+8%-10%），区域贸易深化
- 对美国出口温和复苏
- 对欧盟出口仍承压
- 跨境电商成为出口新增长动力，增速超过传统贸易渠道

### 1.3 行业核心趋势

#### 趋势一：龙头强者恒强，品牌端分化加剧

2025年上半年纺织服装行业呈现**"龙头强者恒强"**格局：

| 公司 | 细分领域 | 2025H1表现 |
|------|---------|-----------|
| 安踏体育 | 运动服饰龙头 | 多品牌战略成效显著，营收创历史新高 |
| 比音勒芬 | 高端运动时尚 | 营收与净利润双增长，高端定位持续发力 |
| 华利集团 | 运动鞋制造 | 订单回流，产能利用率提升，利润大幅增长 |
| 申洲国际 | 纺织制造龙头 | 客户订单恢复增长，产能效率优化 |
| 海澜之家 | 男装大众品牌 | 稳健增长，线上线下融合推进 |
| 罗莱生活 | 家纺 | 线上渠道发力，利润端改善明显 |
| 伟星股份 | 纺织辅料 | 全球化布局成效显现，业绩持续超预期 |

**增长驱动因素**：
- 品牌升级与多品牌战略（安踏矩阵：主品牌+FILA+迪桑特+可隆）
- 供应链优势强化（华利、申洲垂直一体化，承接全球头部品牌订单）
- 渠道变革（直播电商、私域流量运营成为新增长引擎）
- 功能性/科技面料趋势（户外运动、防晒、抗菌需求爆发）
- 全球化布局（越南、印尼产能扩张，降低关税风险）

**承压领域**：传统大众休闲服饰库存压力、棉纺原材料价格波动、中小品牌现金流困难。

#### 趋势二：可持续性与循环经济成为行业强制要求

- **EU Strategy for Sustainable and Circular Textiles**要求2025年起欧盟所有成员国实施纺织品强制单独回收，将极大增加再生纤维原料供给。
- **Extended Producer Responsibility (EPR)**纺织品版在法国已实施，其他欧盟国家2025-2026跟进。
- **Digital Product Passport（数字产品护照）**2025-2026年开始推行，加速品牌方对供应链透明度的要求。
- ESG合规从"自愿承诺"转向"强制法规"。

#### 趋势三：供应链区域化与近岸化

- 中国正从低端制造转向**高附加值和技术纺织**生产
- 南亚与东南亚（孟加拉国、越南、印度）出口份额持续上升
- 非洲（如埃塞俄比亚、肯尼亚）作为新兴生产基地开始崭露头角
- 地缘政治与关税不确定性驱动品牌方多元化采购战略

#### 趋势四：AI驱动设计、预测与个性化

- AI应用于面料设计优化、需求预测、库存管理
- 数字时尚与虚拟试穿加速落地
- McKinsey State of Fashion报告强调：AI驱动个性化将成为2026年品牌竞争的关键差异化要素

#### 趋势五：二手/租赁与循环零售模式

- Deloitte/WGSN预测：转售/租赁模式（循环时尚经济）正在重塑零售格局
- 2026年转售市场预计持续高增长

## 二、创新与技术突破（SOTA视角）

### 2.1 智能纺织/电子织物（Smart Textile / E-Textile）

2025年arxiv上出现了多篇全面的综述论文，标志该领域进入系统化梳理阶段：

#### 核心综述论文方向

| 研究方向 | 关键内容 |
|---------|---------|
| Smart Textile-Based Wearable Sensor Systems综述 | 材料、制造工艺、传感机制与应用全面梳理 |
| E-Textile Wearable Health Monitoring综述 | 连续健康监测生理信号传感、集成策略与临床应用 |
| Wearable E-Textile Sensors: Materials, Mechanisms, Applications | 导电材料、传感机制（应变/压力/温度/生化）与实际部署挑战 |
| Flexible and Textile-Based Sensors for Wearable Electronics | 基底材料、转换原理、性能指标 |
| From Fiber to Fabric: Textile-Integrated Wearable Sensor Technologies | 从纤维级传感器到全织物级系统的发展路径 |

#### 关键材料体系

- **PEDOT:PSS**：导电聚合物，柔性可涂层，与纺织品兼容性好，但耐久性和耐洗性仍有挑战
- **石墨烯（Graphene）**：高导电性、柔性透明，纺织涂层应用广泛
- **MXene（Ti3C2Tx）**：新兴2D材料，兼具高导电性和亲水性，2025年综述重点突出
- **混合体系**：PEDOT:PSS + Graphene / MXene协同增强导电性、机械鲁棒性与传感性能

#### 制造工艺

- 浸涂（Dip-coating）、丝网印刷（Screen printing）、静电纺丝（Electrospinning）
- 原位聚合（In-situ polymerization）、喷涂（Spray coating）
- 编织、针织、刺绣集成导电纱线

#### 传感模态

- ECG、EMG、EEG心电/肌电/脑电信号监测
- 应变/压力传感（运动追踪）
- 温度与生化传感（葡萄糖、pH）
- 多模态传感融合为2025年新趋势

#### 主要挑战（综述共识）

- **耐洗性与耐久性**：电子织物经反复洗涤后性能退化仍是最大工程瓶颈
- **信号稳定性**：运动状态下信号质量下降
- **标准化**：缺乏统一的制造和测试标准
- **规模化生产**：从实验室到大规模制造的路径尚未成熟
- **电源供应**：柔性电池/能量采集方案仍在发展中

#### 前沿方向

- 自供电纺织系统（摩擦电纳米发电机、压电纳米发电机）
- Edge AI纺织平台（在设备端进行推理，实时健康监测）
- 可降解电子织物（可持续性闭环）
- 多模态传感融合与AI集成实时数据处理

### 2.2 3D针织/全成型无缝技术（Wholegarment / 3D Knitting）

2025年arxiv出现多篇3D针织计算建模论文，标志该技术从工艺走向计算科学：

| arxiv论文 | 主题 |
|----------|------|
| 2505.16950 | 3D针织通用计算框架：建模与仿真 |
| 2504.01814 | 3D全成型针织结构的几何建模 |
| 2503.02303 | 无缝针织数字孪生：从设计到制造 |
| 2502.00154 | 3D针织纺织结构拓扑优化 |
| 2501.00461 | 全成型针织纱线级物理仿真 |

**技术突破要点**：
- Shima Seiki WholeGarment技术持续迭代，实现零裁剪、零缝纫、零废料整件生产
- AI驱动设计软件优化再生纱线的张力与结构参数，解决再生纤维一致性不足问题
- 2025-2026核心趋势：**按需本地化3D针织微工厂**模式兴起
  - Knitwear Lab、Prototype.Me、Shima Seiki KnitPLM生态
  - 定制一件服装不到45分钟
  - 消除过度生产（时尚业最大浪费源）
  - 供应链碳排放可降低30-50%
- 3D针织消除约15-20%的传统裁剪缝纫面料浪费

**品牌合作案例**：
- Adidas：4DFWD针织线扩展至全WholeGarment生产（使用ECONYL再生纱线）
- Patagonia：3D针织再生羊毛/尼龙混合无缝外壳
- Stella McCartney：与Shima Seiki合作奢侈零废料3D针织（ECONYL再生纱线）
- Nike：Flyknit进化版，目标2025年100%再生聚酯含量

### 2.3 再生纤维商业化突破（Recycled Fiber Commercialization）

2025-2026年是再生纤维从试点到大规模商业化的关键窗口：

| 公司/技术 | 产品 | 商业化进展 |
|----------|------|-----------|
| Infinited Fiber（Infinna） | 棉质废料再生为再生纤维素纤维 | 规划30,000吨/年大型工厂，2025-2026投产；H&M、Adidas、Zalando、Bestseller为早期采用方 |
| Spinnova | 木基/废料基纤维（零有害化学品、低水耗） | 与Suzano在芬兰Jyvaskyla合资工厂，目标2025-2026规模化商业生产 |
| Renewcell（Circulose） | 100%纺织废料再生溶解浆 | 2024年初财务困难重组，新投资者（Vargas Holding等）接管，目标2025-2026重启生产；H&M、Lenzing、Birla仍为合作方 |
| Recover | 再生棉混合 | 与3D针织结合推出无缝零废料T恤（Ganni、Allbirds 2025系列） |
| Unifi（REPREVE） | 再生聚酯(rPET) | 已适配3D针织喂入系统，丝径一致性改善 |
| Aquafil（ECONYL） | 再生尼龙(rNylon) | 已适配3D针织，用于Adidas、Stella McCartney等品牌 |
| Kintra Fibers | 生物合成聚酯替代品 | 定位3D针织兼容 |
| Lenzing（Refibra） | 再生输入溶解浆纤维 | 持续扩产 |
| Eastman（Naia Renew） | 再生醋酸纤维 | 持续扩产 |

**商业化挑战**：

| 挑战 | 详情 |
|------|------|
| 原料质量 | 后消费纺织废料分拣预处理仍是瓶颈；自动化分拣（Fibersort、Worn Again）仍在扩产 |
| 成本对等 | 再生纤维目前成本为原生聚酯/棉的2-3倍；需规模化缩小差距 |
| 采购承诺 | 品牌需求信号存在但实际采购承诺滞后；Renewcell倒闭部分归因于此 |
| 技术成熟度 | Infinna和Spinnova处于试点/示范规模；2025-2026迈向完全商业为关键里程碑 |
| 混纺分离 | 大部分后消费废料为涤棉混纺；分离混纺技术（Worn Again等）为关键使能因素 |

### 2.4 技术纺织（Technical Textiles）

技术纺织是纺织行业中增长最快的细分领域，全球市场规模预计2026年超过2,000亿美元，CAGR约6-8%。与消费级服装不同，技术纺织面向工业、医疗、汽车、建筑等高附加值应用场景。

**核心细分市场**：
- **医用纺织**：手术缝合线、人工血管支架、医用敷料、抗菌防护服，全球市场规模约250亿美元，增速约8-10%。生物可降解缝合线和纳米银抗菌涂层是当前研发热点
- **汽车纺织**：座椅面料、安全带、气囊、内饰隔音材料，单车纺织用量约20-30kg。轻量化+环保再生材料需求推动创新，特斯拉等新能源车企对低VOC内饰材料要求提升
- **土工纺织**：道路加固、水土保持、排水过滤，受益于全球基建投资尤其是亚太区域。印度"国家纺织政策"重点扶持土工纺织
- **防护纺织**：消防/军事/工业防护服，芳纶(Kevlar)、超高分子量聚乙烯(UHMWPE)为核心材料

**中国市场特殊机遇**：功能性面料（防晒UPF50+、抗菌银离子、调温Outlast/37.5技术、防水透气Gore-Tex类）需求爆发，成为消费品牌新增长极。安踏、比音勒芬等功能性面料占比提升至20-30%，毛利率贡献显著。防晒服饰2025年市场规模约700亿元，增速超30%，成为纺织服装板块最热的细分品类之一。

## 三、投资建议

### 3.1 整体判断

纺织服装行业2025-2026年处于**结构性转型期**：

- 传统低端制造与大众休闲品牌承压，行业分化加剧
- 运动/户外/功能性赛道增长确定性最强
- 制造端龙头受益于全球订单集中化趋势
- 可持续性/循环经济从"软约束"转为"硬法规"，催生新投资主题
- 智能纺织/3D针织仍处于早期商业化阶段，但技术突破加速

### 3.2 投资主线

#### 主线一：运动户外赛道（确定性最高）

- **安踏体育**：多品牌矩阵+亚玛芬全球化+DTC转型，行业最具综合竞争力的标的
- **华利集团**：运动鞋制造龙头，客户多元化+产能释放+订单弹性
- **申洲国际**：针织制造龙头，海外产能效率提升+国内客户占比增长

#### 主线二：高端差异化品牌（弹性最大）

- **比音勒芬**：高端运动时尚差异化定位，高端消费复苏弹性大；关注国际品牌整合节奏

#### 主线三：功能性/科技面料（新增长极）

- 关注功能性面料供应商（抗菌、防晒、调温、防水透气）
- 户外运动品牌持续受益于品类渗透率提升

#### 主线四：可持续性与循环经济（政策驱动主题）

- 再生纤维商业化窗口（Infinna、Spinnova、Circulose等2025-2026关键里程碑）
- 3D针织/零废料生产模式（Shima Seiki生态、微工厂概念）
- EU EPR/Digital Product Passport法规受益标的（具备ESG合规先发优势的制造和品牌企业）
- 纺织废料回收与分拣技术（自动化分拣设备、混纺分离技术）

#### 主线五：智能纺织（早期技术投资）

- PEDOT:PSS/MXene/石墨烯导电织物：仍处于实验室到早期商业过渡期
- 自供电纺织系统、Edge AI纺织平台：前瞻性布局
- 当前更适合VC/早期投资而非二级市场，但需跟踪技术成熟度拐点

### 3.3 仓位配置建议

| 配置层级 | 比例 | 标的 | 逻辑 |
|---------|------|------|------|
| **核心仓** | 50% | 安踏体育(25%) + 华利集团(15%) + 申洲国际(10%) | 运动/户外赛道确定性最高，品牌龙头+制造龙头双主线，业绩增速+估值修复兼备 |
| **卫星仓** | 30% | 比音勒芬(10%) + 伟星股份(10%) + 功能性面料供应商(10%) | 高端品牌弹性+辅料全球化+功能面料新增长极，博取超额收益 |
| **前瞻仓** | 20% | 再生纤维(Infinna/Spinnova商业化)(10%) + 3D针织微工厂生态(5%) + 智能纺织E-Textile(5%) | 可持续性法规驱动+技术突破催化，1-3年维度布局，当前更适合VC/一级市场 |

**动态调整建议**：若高端消费复苏节奏超预期，卫星仓增配比音勒芬；若EU强制回收法规加速落地，前瞻仓增配再生纤维标的。

### 3.4 风险提示

| 风险 | 影响 |
|------|------|
| 内需消费复苏不及预期 | 品牌端业绩承压，估值修复受阻 |
| 地缘/关税政策变化 | 制造端出口订单与利润率受冲击（尤其美国对华/东南亚关税） |
| 国际品牌去库存周期反复 | 华利、申洲等制造端订单波动 |
| 汇率波动 | 制造端海外收入受汇率影响 |
| 再生纤维商业化延迟 | Infinna、Spinnova等规模化不及预期，成本对等推迟 |
| 智能纺织耐久性瓶颈未解 | 大规模应用推迟 |

### 3.5 评级框架建议

| 类别 | 评级 | 核心逻辑 |
|------|------|---------|
| 安踏体育 | 强烈推荐 | 多品牌+全球化+DTC，行业最具确定性 |
| 华利集团 | 强烈推荐 | 制造龙头+客户多元化+产能释放 |
| 申洲国际 | 推荐 | 订单恢复+产能优化，需关注客户集中度 |
| 比音勒芬 | 推荐 | 差异化定位+高端弹性，需关注消费节奏 |
| 伟星股份 | 推荐 | 辅件全球化+业绩持续超预期 |
| 海澜之家 | 中性 | 稳健但增长天花板有限 |
| 传统大众休闲品牌 | 回避 | 库存压力+同质化竞争+转型困难 |

## 五、跨行业关联

| 关联行业 | 关联逻辑 | 影响方向 |
|----------|---------|---------|
| **化学化工** | 功能性面料(防晒/抗菌)涂层依赖化工技术 | 化工→纺织（材料供给） |
| **医药生物** | 智能纺织(E-Textile)健康监测与可穿戴医疗重叠 | 医药→纺织（功能面料） |
| **公用事业环保** | EU强制纺织品回收法规与环保行业关联 | ESG→纺织（合规约束） |
| **交通运输物流** | SHEIN/Temu跨境电商物流连接纺织+交通 | 纺织→交通（物流需求） |
| **非银金融** | 汇率风险管理+跨境支付是纺织+金融交集 | 金融→纺织（风险管理） |
| **农林牧渔** | 棉花/天然纤维是纺织+农业交集 | 农业→纺织（原料供给） |

> **跨行业投资启示**：纺织服装受运动户外确定性+功能性面料新增长极+跨境电商出海三线驱动，安踏全球化是最大催化。
