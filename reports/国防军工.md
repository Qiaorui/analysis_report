# 国防军工 投资研究报告

> 研究日期：2026年6月 | 覆盖周期：2025-2026

---

## 一、行业现状与趋势（研报视角）

### 1.1 全球国防支出创历史新高

根据斯德哥尔摩国际和平研究所（SIPRI）2025年发布的数据，**2024年全球军费开支达到2.44万亿美元**，同比增长9%（实际 terms），为1988年有记录以来最大年度增幅，也是连续第10年增长。主要驱动因素包括：

- 俄乌战争持续推动欧洲国防开支大幅上升
- 中东地缘紧张局势加剧
- 北约成员国加速达到2% GDP国防开支目标
- 亚太地区（日本、印度、澳大利亚、韩国）国防预算快速增长

**全球国防支出前五名**：美国（占比最大）、中国（第二）、俄罗斯、印度、英国。

### 1.2 中国国防预算持续增长

中国2025年国防预算约**1.81万亿元人民币**，同比增长约7.2%，延续近年来稳定增长态势。国防预算占GDP比重维持在1.3%-1.4%左右，低于全球平均水平和北约2%标准，仍有提升空间。2026年国防预算预计同比增长约7.0-7.5%，延续稳定增长节奏。

**2025-2026军工订单最新进展**：
- 十四五收官年（2025）延迟采购任务加速完成，多家军工龙头2024年报显示存货原材料和在产品增长，预示生产节奏加快
- 航发动力2024年末合同负债约68亿元，2025Q1营收同比增长15%，订单恢复信号初步显现
- 申万宏源研报指出：2025年下半年起订单加速释放，2026年进入十五五新周期上行
- 军品定价机制调整压力逐步消化，关注毛利率企稳回升信号

### 1.3 A股军工行业：拐点确认，从周期走向成长

多家头部券商研报一致认为，**2025年是军工行业订单与业绩拐点确认之年**，核心逻辑如下：

| 券商 | 报告标题 | 核心观点 |
|------|----------|----------|
| 中信证券 | 军工行业2025年投资策略：守正出奇，把握结构性机遇 | 关注信息化、新材料、航空发动机等细分赛道 |
| 中金公司 | 国防军工行业2025年度展望：改革深化，景气上行 | 军工集团资产证券化、股权激励，2025-2026增速改善 |
| 华泰证券 | 军工2025年策略报告：从周期走向成长，聚焦新质战斗力 | 新质战斗力（无人装备、精确打击、电子对抗）为核心方向 |
| 开源证券 | 军工行业深度报告：2025年拐点确认，六大方向布局 | 航空发动机、导弹弹药、军用电子、卫星互联网、新材料、无人装备 |

| 东方证券 | 军工行业2025年投资策略：困境反转，精选优质标的 | 估值处于历史低位，困境反转逻辑明确 |
| 广发证券 | 军工2025年策略：重点关注军工电子与航天领域 | 军工电子信息化与卫星互联网最具成长性 |
| 招商证券 | 国防军工行业2026年前瞻：新周期启动，三条主线布局 | 装备升级、信息化智能化、军民融合与出海 |

**行业关键拐点信号**：

1. **预收款/合同负债回升**——订单拐点最直接的财务信号
2. **存货结构变化**——原材料和在产品增长预示生产加速
3. **季度业绩环比改善**——尤其是Q2-Q3同比增速转正
4. **公告大额合同**——上市公司披露重大订单/框架协议

**机构预测**：2025年军工行业整体营收增速可达15%-20%，净利润增速20%-30%。订单拐点大概率在2025年上半年显现，业绩拐点在下半年兑现。

| 军贸出口 | 中国军工产品国际竞争力提升，军贸订单成为新增长极 |
| 价格调整落地 | 军品定价机制调整压力逐步消化，毛利率有望企稳回升 |
| 产能释放 | 此前扩产产能逐步进入释放期，配合订单恢复增强业绩弹性 |

### 1.6 电子战与军工电子信息化

电子战/信息化是"新质战斗力"的核心构成要素，2025-2026年呈现以下趋势：

- **认知电子战（Cognitive EW）**：AI驱动的自适应干扰与信号识别加速工程化
- **多域电子战**：从频谱对抗扩展至陆、海、空、天、网多域融合
- **国产替代深化**：射频芯片、FPGA、高速ADC/DAC国产化率目标2026年达70-80%
- **无人平台电子战**：无人机/无人舰载电子战系统成为新增长点

**市场规模**：

- 全球电子战市场：2025年约180亿美元，2026年突破200亿美元（CAGR 8-10%）
- 中国军工电子信息化市场：2025年超1500亿元，2026年接近1800亿元
- 国防信息化预算占比：预计从2024年约35%提升至2026年40%以上

### 1.7 估值与风险

**估值水平**：军工板块经历2023-2024年深度调整后，估值处于历史低位区间（中证军工指数PE约40-50倍，低于历史中枢60倍），困境反转逻辑明确。核心标的中：
- 航发动力PE约40-45倍，处于历史偏低区间，订单恢复后有望估值修复
- 振华科技PE约30-35倍，军工电子赛道稀缺性溢价合理
- 中航沈飞PE约50-55倍，整机龙头享有军工溢价
- 紫光国微PE约35-40倍，FPGA国产替代主线但2024年业绩承压

**历史估值对比**：军工板块在2019-2021年上行周期中PE中枢约60-80倍，当前PE约40-50倍处于历史20-30分位，估值修复空间约30-50%。但需注意军工行业估值长期偏高是常态（成长性溢价+信息不对称溢价），不能简单与传统消费/金融行业PE对标。

**风险提示**：

- **订单恢复节奏可能低于预期**：十四五收官年任务虽需加速完成，但实际订单下达节奏受多重因素影响，需以合同负债季度变化作为验证指标
- **军品价格调整仍可能影响毛利率**：军品定价从"成本+5%"向"竞标定价"转型仍在推进中，短期可能压缩龙头利润率，但长期有利于成本控制和效率提升
- **产能释放与订单匹配存在时差**：此前扩产产能进入释放期，若订单恢复滞后则产能利用率不足，影响盈利弹性
- **国际军贸受政治因素影响存在不确定性**：军贸出口为增量方向，但受国际地缘政治变化影响较大
- **军工集团资产证券化进度不确定**：军工集团整体资产证券化率约30-40%，提升空间大但节奏不确定

## 二、创新与技术突破（SOTA视角）

### 2.1 无人系统与蜂群技术

**无人机蜂群**是当前军事AI最活跃的研究方向。2025年arxiv上涌现大量相关survey论文：

| 论文方向 | 关键内容 |
|----------|----------|
| 蜂群机器人技术综述 | 分散式决策、通信韧性、多智能体强化学习（MARL）协同 |
| 军事蜂群作战：技术与伦理挑战 | 目标识别算法、蜂群对抗蜂群战术、致命自主武器系统（LAWS）伦理框架 |
| MARL蜂群协同综述 | 合作任务分配、对抗环境实时适应、规模扩展挑战 |
| 电子战条件下蜂群通信韧性 | 分散式mesh网络、跳频协议维持蜂群凝聚力 |
| 蜂群智能战术应用 | 路径规划、动态任务重分配、编队控制 |
| 自主蜂群对抗博弈论分析 | 微分博弈建模攻击/防御策略、纳什均衡分析 |
| 蜂群AI对抗鲁棒性 | 对抗性扰动攻击目标检测、蜂群通信欺骗、防御对策 |

**关键趋势**：蜂群技术从实验室仿真走向实战化部署，但面临通信韧性、AI对抗攻击、伦理监管三大挑战。

### 2.2 高超声速武器

全球高超声速武器研发进入加速阶段：

- **美国**：陆军Long-Range Hypersonic Weapon (LRHW) 2025年初完成飞行测试；DARPA HAWC项目进入Phase 3，整合自主导航算法与网络安全协议
- **中国**：宣称测试Mach 7+自主高超声速无人机（西方分析人士认为难以独立验证）
- **俄罗斯**：Avangard高超声速滑翔飞行器继续部署，声称增强自主瞄准能力
- **印度**：DRDO HSTDV测试成功，计划2026年整合自主导航与网络安全通信链路

**核心挑战**：极端速度+自主决策的组合创造了人类监督、问责和国际法的空前难题（UNIDIR政策报告）。

### 2.3 AI驱动国防系统

arxiv 2025年相关survey论文：

| 论文 | 核心内容 |
|------|----------|
| AI驱动国防系统综合综述 | 自主威胁检测、对抗性ML防御、AI军事决策支持系统 |

### 2.4 军事网络安全

**CISA威胁评估**（2025年）指出自主军事平台的网络安全风险：

- 对抗性AI攻击（adversarial AI attacks）
- GPS欺骗（GPS spoofing）
- 供应链攻击（supply chain compromise）
- 实时通信干扰（real-time communication jamming）

**NATO应对措施**：2025年发布自主武器系统网络安全防御框架，强调加密标准、故障安全协议、对抗韧性测试。

**美国FY2026国防预算**：提议约180亿美元用于AI与自主系统，其中大量分配给高超声速无人机研究、自主平台网络安全韧性及下一代武器系统集成。

### 2.5 卫星互联网与低轨星座军事应用

Starlink在乌克兰战场的表现成为LEO卫星互联网军事价值的实战验证：

- **通信韧性**：在传统基础设施被摧毁后维持通信
- **无人系统连接**：支持无人机超视距操作、火炮瞄准、实时情报共享
- **SpaceX Starshield**：军用版Starlink，加密通信、模块化卫星总线、政府定制载荷
- **抗干扰能力**：经历大量俄罗斯电子战攻击后持续升级anti-jamming能力
- **美国SDA**：正在建设自己的LEO国防星座（Tranche 2/3），借鉴Starlink架构

**2025-2026关键进展**：

- Starshield卫星批量发射部署
- SDA Tranche 2 LEO国防卫星发射
- 直接到手机（direct-to-cell）军事应用扩展
- 星间激光链路扩展，减少地面站依赖

**中国应对**：发展"GW星座"等自主LEO星座计划，作为对Starlink军事潜力的战略回应。

## 三、投资建议

### 3.1 2025年策略：困境反转 + 拐点确认

**核心逻辑**：军工板块经过2023-2024年深度调整，估值处于历史低位，2025年订单恢复与业绩拐点确认形成困境反转。

**优先布局方向**（确定性较高）：

1. **航空发动机**——新型号批产+消耗属性，业绩弹性最大
2. **导弹/精确制导**——订单恢复弹性大，消耗属性强

### 3.2 2026年策略：新周期启动 + 成长属性强化

**核心逻辑**：从周期走向成长，新质战斗力相关方向成为结构性超额收益来源。

**重点布局方向**（成长性更高）：

1. **无人装备**——蜂群无人机、无人舰艇等自主平台
2. **卫星互联网**——中国低轨星座建设+卫星通信装备
3. **认知电子战/信息化**——AI+电子战融合、数据链升级
4. **新材料**——碳纤维、高温合金等军民两用材料

**核心标的**：航天电子、中国卫星、光威复材、西部超导

### 3.3 三条投资主线（招商证券框架）

1. **装备升级主线**：航空、航天、船舶传统装备换代订单确定性
2. **信息化与智能化主线**：军工电子、数据链、AI决策系统成长性
3. **军民融合与出海主线**：军贸出口、商用航天、军民两用技术弹性

### 3.4 风险控制要点

| 风险类型 | 应对策略 |
|----------|----------|
