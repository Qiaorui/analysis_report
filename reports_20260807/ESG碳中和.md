# ESG碳中和行业调研报告

> 时点: 2026-08-07 | 评级: ⚠️ 谨慎(光伏困境/碳市场待成熟) | 核心标的: 宁德时代/阳光电源

---

## 一、宏观相关性与景气度

### 1.1 "十五五"碳达峰行动方案 — 行业纲领性政策

2026年7月5日国务院印发(国发〔2026〕22号), 核心目标:
- 到2030年单位GDP CO₂排放比2025年**降低17%**
- 非化石能源消费占比达**25%**
- 风电+太阳能装机≥**28亿千瓦**, 常规水电≥4.1亿千瓦, 核电运行≥1.1亿千瓦
- 新增西电东送能力8000万千瓦
- 新增用电由新增清洁能源覆盖
- 逐步明确重点行业可再生能源消费最低比重目标

### 1.2 碳交易市场

- 全国碳市场: 2026年覆盖行业扩大(待核实: 是否纳入钢铁/水泥/铝)
- CCER(国家核证自愿减排量): 2024年重启后, 2026年运行状况待核实
- 碳价: 全国碳市场碳价待核实(EU ETS约€60-80/ton, 中国远低于此)
- 绿电交易: 与碳市场衔接, 绿电环境价值逐步体现

### 1.3 光伏产业链: 深度困境

| 指标 | 数值 | 判断 |
|------|:---:|------|
| 隆基绿能2025净利 | **-64.2亿** | 巨亏 |
| 通威股份2025净利 | **-95.5亿** | 巨亏 |
| 晶澳科技2025净利 | **-46.1亿** | 巨亏 |
| TCL中环2025净利 | **-92.6亿** | 巨亏 |

**行业判断**: 光伏全产业链产能严重过剩, 硅料/硅片/电池片/组件价格跌破成本线, 全行业亏损。产能出清需要时间, 短期看不到拐点。

### 1.4 储能/锂电: 龙头强者恒强

- **宁德时代**: 2025净利722亿, Q1+48.5%, 全球动力电池龙头
- 阳光电源: 2025净利134.6亿, 逆变器+储能双驱动
- 天赐材料: Q1同比+1005.8%(基数极低), 电解液龙头

### 1.5 国际维度

- 欧盟碳边境调节机制(CBAM): 2026年起正式征收, 影响中国出口企业
- 美国IRA法案: 补贴本土新能源, 中国电池企业赴美建厂(宁德时代/国轩高科)
- 全球碳定价机制扩散, 碳关税趋势不可逆
- 中国新能源出口(光伏/电池/电动车)面临贸易壁垒

### 1.6 金价$4500+/油价$83+

- 金价上涨利好贵金属相关(不直接影响ESG)
- 油价上涨间接利好新能源替代逻辑

## 二、产业链分析

```
碳中和产业链:
  碳减排: 新能源发电(风/光/水/核) → 电网/储能 → 终端用电
  碳交易: 碳配额(CEA) / CCER / 绿证 / 绿电交易
  碳捕集: CCUS技术(待核实: 商业化进展)
  
光伏产业链: 硅料(通威) → 硅片(隆基/TCL中环) → 电池片(通威/晶澳) → 组件(隆基/晶澳)
                    ↓ 全链亏损, 产能过剩
锂电产业链: 锂矿 → 正极/负极/电解液/隔膜 → 电池(宁德时代) → 整车/储能
                    ↓ 龙头盈利, 中游分化
```

## 三、核心标的分析

### 3.1 宁德时代(300750) — 全球锂电之王

| 指标 | 数值 | 判断 |
|------|:---:|------|
| 现价 | 388.07元 | 52周位63% |
| PE/PB | 21.1 / 4.73 | PE分位16%, PB分位24% |
| 市值 | **16532亿** | |
| 2025净利 | **722.0亿** | 超强 |
| 2026Q1净利 | 207.4亿 | **Q1同比+48.5%** |

**治理质量**: 曾毓群控制, 技术驱动型企业, 研发投入大。全球市占率~37%(动力电池), 护城河深。麒麟电池/神行电池/凝聚态电池持续创新。

**投资逻辑**:
- ✅ PE分位仅16%, 相对于增速(48.5%)极为合理(PEG<0.5)
- ✅ 全球龙头地位稳固, 技术+规模双壁垒
- ✅ 储能业务高增长, 第二曲线
- ⚠️ 52周位63%, 不便宜
- ⚠️ 地缘风险(美国市场限制)

### 3.2 阳光电源(300274) — 逆变器+储能

## 四、SOTA技术与前沿论文

- **钙钛矿太阳能电池**: 效率突破30%+(待核实: 商业化进展), 可能颠覆传统硅基光伏
- **固态电池**: 能量密度提升, 安全性改善(宁德时代/丰田等推进)
- **长时储能**: 液流电池/压缩空气/重力储能(十五五政策重点支持)
- **绿氢**: 电解水制氢+可再生能源(十五五规划"风光氢氨醇一体化")
- **CCUS**: 碳捕集利用与封存(待核实: 中国示范项目进展)
- **论文方向**: arXiv搜索carbon trading未返回相关结果; 碳交易/ESG论文主要集中在Energy Economics、Journal of Environmental Economics等期刊

## 六、总结与评级

| 维度 | 结论 |
|------|------|
| 政策 | "十五五"碳达峰方案纲领性文件, 长期利好 |
| 光伏 | 全链亏损, 产能出清尚需时日, 不建议抄底 |
| 锂电/储能 | 宁德时代强者恒强, Q1+48.5%验证 |
| 碳交易 | 市场尚不成熟, 碳价低, 缺乏直接受益标的 |
| ESG投资 | 长期趋势, 但A股ESG基金规模仍小 |

**综合评级**: ⚠️ 谨慎(分化极大)

- **强烈推荐**: 宁德时代(PE分位16%、Q1+48.5%、全球龙头)
- **观望**: 阳光电源(Q1下滑需跟踪)、光伏产业链(等待出清信号)
- **不推荐**: 光伏四大(隆基/通威/晶澳/TCL中环)持续巨亏
- **碳交易**: 概念性强, 缺乏直接受益且业绩好的标的
