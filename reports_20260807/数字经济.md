## 一、行业界定与产业链全景

### 1.1 什么是"数字经济"？

数字经济是以数据资源为关键要素、以现代信息网络为主要载体、以信息通信技术融合应用为重要推动力的经济形态。与"AI/软件"行业的区别与交叉：

| 维度 | 数字经济 | AI/计算机软件 |
|------|---------|--------------|
| 核心驱动力 | 数据要素 + 数字基建 + 产业数字化 | 算法 + 算力 + 应用 |
| 政策口径 | 国家数据局主管，"数据要素×"为主线 | 工信部/科技部主管，AI大模型为主线 |
| 收入模式 | 数据交易、公共数据运营、数字基建服务 | SaaS订阅、软件授权、AI推理 |
| 重叠地带 | 数据要素平台、数据资产入表、AI训练数据 | AI for Data（用AI做数据服务） |

**关键判断**：数字经济与AI/软件高度交叉但本质不同——数字经济更强调**数据作为生产要素的市场化流通**，AI更强调**算法和算力**。二者交叉点在于：AI需要高质量数据训练，数据要素市场化为AI提供"燃料"。

### 1.2 产业链四段

```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│ 上游·数据要素 │──→│ 中游·数字基建 │──→│ 下游·产业数字化│──→│ 终端·数字政务 │
│              │   │              │   │              │   │              │
│ 数据采集      │   │ 算力中心      │   │ 工业数字化    │   │ 政务云        │
│ 数据确权      │   │ 东数西算      │   │ 金融数字化    │   │ 数字政府      │
│ 数据交易      │   │ 算力网络      │   │ 农业数字化    │   │ 智慧城市      │
│ 数据资产入表  │   │ 服务器/芯片   │   │ 服务业数字化  │   │ 一网通办      │
└─────────────┘   └─────────────┘   └─────────────┘   └─────────────┘
```

### 2.3 国际维度

**全球数字经济规模**：2025年中国数字经济增加值约49万亿元，占GDP比重约35%（从20.9%增长至39.8%的历史进程）。

**中美欧三方对比**：

| 维度 | 中国 | 美国 | 欧盟 |
|------|------|------|------|
| 数据跨境立场 | 安全有序流动 | 从自由流动→国安审查（14117行政令） | GDPR隐私优先+充分性认定 |
| 核心制度 | 数据二十条+数据资产入表 | 行政令管控敏感数据 | 与韩/新达成充分性认定 |
| 竞争优势 | 数据规模+政策支持 | 技术领先+市场化 | 规则制定权+隐私保护 |
| 2025-2026动态 | 国家数据局加速推进 | 限制对华敏感数据出口 | 跨境数据流动框架扩展 |

**国际竞争判断**：中国在数据规模和政策力度上具有优势，但在数据跨境流动自由度和核心技术（高端芯片、EDA工具）上仍受制于美国。"数据主权"概念正在全球范围内强化。

### 3.2 前沿研究判断

1. **数据定价是核心学术热点**：多篇论文聚焦"数据如何定价"，但尚未形成统一理论框架，传统边际成本定价法不适用于数据（数据非竞争性、非排他性）。
2. **ML/AI驱动定价是新兴方向**：利用机器学习对数据资产进行估值，是从"成本法"向"收益法"转型的技术路径。
3. **数据资产折旧理论刚起步**：arXiv 2601.12339将LLM视为有折旧的数字资产，对数据资产的会计处理有理论启示。
4. **学术-政策互动紧密**：国家数据局2025/2026年连续发布课题征集，学术研究与政策制定高度联动。
