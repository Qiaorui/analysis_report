# 美容护理行业独立调研报告

> 调研时点: 2026-08-07 | 数据截至: 2026Q1 | 核心标的: 珀莱雅 / 爱美客 / 贝泰妮

---

## 一、行业全景与宏观相关性

### 1.1 行业格局

中国美容护理市场2025年规模约8000亿元，其中:
- 化妆品(护肤+彩妆): ~4500亿，国货份额提升至约40%(vs. 2020年约25%)
- 医美: ~3000亿，增速从20%+回落至约8-10%
- 个护: ~500亿

国货替代是核心主线——珀莱雅/薇诺娜/彩棠等品牌份额快速提升，外资(雅诗兰黛/兰蔻/SK-II)在华份额持续下降。

### 1.2 宏观相关性

- **消费降级/口红效应**: 化妆品属于"小额奢侈品"，经济下行时消费者从高端转向性价比国货。珀莱雅/薇诺娜直接受益。
- **医美监管趋严**: 2024-2025年监管加强(水货/假货打击+机构合规化)，短期压制行业增速(爱美客Q1净利-32.8%)，但长期利好合规龙头。
- **社媒/直播**: 抖音/小红书种草+直播带货成为化妆品核心渠道(占比40%+)，利好具备内容营销能力的国货品牌。
- **人口结构**: 抗衰需求(30-45岁女性)持续增长，Z世代(18-25岁)更注重成分/功效。
- **油价/金价**: 对美容护理直接影响有限，但避险情绪推升防御板块估值。

### 1.3 国际维度

- **国货替代加速**: 珀莱雅2025年双十一超越欧莱雅成为天猫护肤第一(待核实)，标志性事件。
- **出海**: 珀莱雅/花西子尝试东南亚市场，但贡献极小(<2%)。
- **医美上游**: 爱美客的玻尿酸/胶原蛋白产品具有全球竞争力(待核实: 海外注册进展)。
- **外资撤退/调整**: 雅诗兰黛2025年在华收入-15%+(待核实)，被迫降价促销。

## 二、产业链分析

### 化妆品产业链
```
上游: 原料(玻尿酸/胶原蛋白/活性肽) → 包材 → 代工(OEM/ODM)
中游: 品牌商(珀莱雅/贝泰妮/华熙生物) → 国际品牌(雅诗兰黛/欧莱雅)
下游: 线上(天猫/抖音/小红书 40%+) → 线下(百货/CS渠道/新型零售)
```

### 医美产业链
```
上游: 原料(玻尿酸/胶原蛋白/PDRN等) → 器械(光电设备)
中游: 产品商(爱美客/华熙生物/昊海生科) → 器械商(待核实)
下游: 医美机构(朗姿/美莱等) → 消费者
```

**关键变化**:
- **重组胶原蛋白**: 巨子生物(港股)/锦波生物(北交所)引领，传统玻尿酸龙头(华熙/爱美客)面临技术路线替代风险。
- **功效护肤**: "成分党"驱动，烟酰胺/视黄醇/胜肽等成分成为品牌差异化关键。
- **医美合规化**: 水光针/肉毒素等品类监管趋严，灰色市场被压缩。

### 3.2 盈利质量

| 指标 | 珀莱雅 | 爱美客 | 贝泰妮 | 华熙生物 |
|------|--------|--------|--------|---------|
| 2025营收(亿) | 112.0 (+6.7%) | 30.3 (+5.5%) | 57.4 (+3.9%) | 54.0 (-2.7%) |
| 2025净利(亿) | 15.0 (-3.5%) | 12.9 (-34.1%) | 5.1 (+0.5%) | 2.9 (-36.5%) |
| ROE | 25.8% | 17.0% | 8.2% | 17.0% |
| Q1净利(亿) | 3.7 (-6.0%) | 3.0 (-32.8%) | 0.7 (+132.8%) | 0.6 (-36.5%) |

**关键发现**:
- **珀莱雅**: 国货化妆品龙头，但2025年出现上市以来首次净利下滑(-3.5%)，Q1继续下滑-6%。可能原因: 营销费用高企(抖音投流成本上升)+竞争加剧。但ROE仍高达25.8%，PE分位2%处于历史最低区间。
- **爱美客**: 医美上游龙头(嗨体/濡白天使)，2025年净利-34.1%反映监管趋严+消费降级+胶原蛋白替代冲击。Q1继续-32.8%，尚未见底。PE 27.8x在医美赛道不算贵，但增速恶化。
- **贝泰妮(薇诺娜)**: 敏感肌护肤品牌，2025年营收+3.9%恢复增长，但净利仅+0.5%(增收不增利)。Q1净利+132.8%是强劲反弹(*待核实: 是否有低基数效应*)。ROE仅8.2%是核心短板。
- **华熙生物**: 玻尿酸原料龙头，转型C端品牌(润百颜/夸迪/米蓓尔)效果不佳。2025年营收/净利双降，Q1继续恶化。PE 73x仍不便宜。

### 3.3 现金流与扣非

- 珀莱雅: 品牌型企业OCF通常与净利匹配，但营销费用前置可能导致季度波动。
- 爱美客: 产品型公司毛利率>90%，OCF通常优于净利。
- *具体数据待核实*。

| 分红 | 一般 | 一般 | 一般 | 一般 |

**核心风险**:
- **珀莱雅**: 营销费用率过高(约45%)，一旦增速放缓则利润率承压。大单品依赖(红宝石/双抗精华)。
- **爱美客**: 监管政策不确定性(肉毒素/水光针等品类)。胶原蛋白替代冲击。
- **贝泰妮**: 品牌单一(薇诺娜贡献>90%收入)，ROE偏低。
- **华熙生物**: C端转型失败，B端原料业务受胶原蛋白技术路线替代威胁。

## 五、论文与技术维度

- **重组胶原蛋白**: 合成生物学制备重组III型/ XVII型胶原蛋白，巨子生物(港股)引领。arXiv/期刊: 精密发酵生产人源化胶原蛋白(*待核实: 具体论文*)。
- **外泌体/外泌蛋白**: 新一代抗衰原料，爱美客/华熙均有布局(*待核实*)。
- **AI+皮肤检测**: AI辅助皮肤诊断+个性化护肤方案，贝泰妮在布局。
- **微针/透皮递送**: 纳米微针/可溶性微针贴片技术(待核实: arXiv论文)，可能改变医美给药方式。

## 六、综合评估与投资建议

| 标的 | 评级 | 核心逻辑 |
|------|------|---------|
| 珀莱雅 | **增持** | 国货化妆品龙头地位稳固，PE 15.5x处于2%分位历史极低。净利下滑是短期压力(营销投入期)，ROE 25.8%仍优秀。适合逢低配置 |
| 爱美客 | **中性** | 医美监管+消费降级+技术替代三重压力。Q1仍在恶化(-32.8%)，需等业绩企稳信号。PE 27.8x合理但不便宜 |
| 贝泰妮 | **中性偏积极** | Q1净利+133%是强劲反弹，但需确认可持续性。ROE仅8.2%制约长期价值。敏感肌赛道有差异化但品牌单一 |
| 华熙生物 | **回避** | 转型失败，营收/净利持续恶化，PE 73x严重高估 |

**行业总结**: 美容护理处于"国货替代进行时+医美监管阵痛期"。化妆品(珀莱雅)优于医美(爱美客)。行业整体估值已回落至历史低位，但增速放缓是核心矛盾。
