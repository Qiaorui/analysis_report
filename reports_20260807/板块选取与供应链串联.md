## 二、供应链串联(归线全覆盖)

### 线1: 创新药出海线 ⭐⭐⭐(最强)
```
创新药研发 → 临床/审批 → 商业化/出海
   恒瑞医药      百济神州      康方生物
   华东医药      
```
**最强节点**: 医药生物(恒瑞/华东) + 生物科技(百济/康方)
**逻辑**: 降息预期→biotech估值弹性最大; License-out/双抗全球化证明中国创新药已达全球一线; 基药目录扩容提供国内增量

### 线2: 高股息防御线 ⭐⭐⭐(核心底仓)
```
水电/核电 → 银行 → 家电 → 食饮 → 交运
 长江电力    招商银行   格力电器   贵州茅台   顺丰控股
 中国核电    宁波银行   美的集团   伊利股份   中远海控
```
**最强节点**: 公用事业(长江电力) + 家电(格力) + 交通运输(顺丰)
**逻辑**: 震荡筑底阶段, 高股息防御仍是核心配置。但30日+11.2%后短期获利回吐压力存在。格力PE 7.7x+顺丰PE 1%分位是估值最有保护的标的

### 线3: 资源/能源/黄金线 ⭐⭐
```
黄金(避险) → 铜(AI需求) → 石油(地缘) → 化工(周期底)
 紫金矿业      紫金矿业      中国海油      万华化学
 山东黄金      洛阳钼业      中国石油      天赐材料
```
**最强节点**: 有色金属(紫金矿业) + 化学化工(万华化学)
**逻辑**: 金价$4500+三重逻辑(避险+去美元化+央行购金)共振; 铜受益AI数据中心需求; 化工周期底部Q1盈利拐点确认

### 线4: 国防军工+航天线 ⭐⭐
```
军费确定 → 装备/军贸 → 商业航天
 中航沈飞    紫光国微    斯瑞新材
 航发动力    中航光电    航天电器
```
**最强节点**: 国防军工(中航沈飞)
**逻辑**: 十五五军费增长确定+中东冲突推升防空/海军装备需求; 商业航天千帆+GW组网加速

### 线5: 电网/新能源线 ⭐⭐
```
电网投资(十五五) → 特高压 → 储能/新能源
 国电南瑞          平高电气    宁德时代
 许继电气          思源电气    阳光电源
```
**最强节点**: 电气设备(国电南瑞) + 新能源(宁德时代)
**逻辑**: 十五五电网投资4万亿, 特高压建设加速; 宁德ROE 25%+PE 19.8%分位, 阳光ROE 31%+PE 7.2%分位

### 线6: 券商/金融改革线 ⭐
```
成交量回暖 → 并购重组 → 碳排放权交易
 中信证券      中信证券      中信证券
 东方财富      东方财富      
```
**最强节点**: 非银金融(中信证券/东方财富)
**逻辑**: 券商PE分位<10%+2025净利暴增; 三重催化(成交量+并购+碳交易)

### 线7: 前沿卫星线(轻仓) ⭐
```
具身智能 → 商业航天 → (量子观察)
 汇川技术    斯瑞新材    国盾量子(概念)
 绿的谐波    航天电器    
```
**最强节点**: 机器人(汇川技术PE 20%分位)
**逻辑**: 宇树IPO提供定价锚, 人形机器人2025年1.8万台→2026年有望翻倍
