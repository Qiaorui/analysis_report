## 一、宏观相关性与景气度

### 1.1 猪周期: 深度磨底, 产能出清迟缓

| 指标 | 数值(2026-08-07) | 位置判断 |
|------|:---:|------|
| 外三元猪价 | **10.36元/kg** | 接近成本线底部 |
| 内三元猪价 | 10.54元/kg | 磨底 |
| 土杂猪 | 10.10元/kg | 全面亏损区 |
| 猪粮比 | **4.37:1** | 远低于盈亏线(~7:1) |
| 玉米(饲料) | 2370元/吨 | 低位稳定 |
| 豆粕(饲料) | 2911元/吨 | 低位 |

**判断**: 猪价10.36元/kg, 对应自繁自养成本约14-15元/kg, 行业处于深度亏损区间。猪粮比4.37:1远低于盈亏平衡线(~7:1), 养殖全面亏损。新闻面显示"磨底"、"钝刀割肉"、"供过于求格局未改", 8月样本猪企出栏增3.74%, 供给压力持续。三季度后期供给压力或实质性缓解, 但短期反弹阻力大。

**周期定位**: 当前处于猪周期**下行末段/底部磨底期**, 对应2023-2024年产能扩张后的消化阶段。能繁母猪存栏去化缓慢(待核实: 最新月度数据), 散户退出但规模化场(牧原、温氏等)逆周期维持产能, 导致去化速度慢于历史周期。

### 1.2 粮食安全与种业

- 转基因玉米/大豆商业化进展待核实(2024年已有品种审定, 2026年推广面积数据待核实)
- 粮食价格: 主粮(稻谷、小麦)最低收购价政策托底, 整体平稳
- 饲料原料(玉米2370元/吨、豆粕2911元/吨)低位, 利好养殖成本端

### 1.3 国际维度

- 全球粮食价格: FAO粮食价格指数2025-2026年整体回落(待核实)
- 大豆进口依赖度高(巴西、美国), 中美贸易摩擦影响待评估
- 猪种进口(丹麦、英国种猪)正常, 无重大断供风险

### 1.4 中东/大宗商品传导

- 布伦特原油$83↑→ 饲料运输成本微增, 但影响有限
- 玉米/豆粕国际价格低位, 进口成本可控
- 金价$4500+ 对农产品无直接传导

## 二、产业链分析

```
上游(饲料/种猪/疫苗) → 中游(养殖) → 下游(屠宰/加工/消费)
     ↓                    ↓                    ↓
  玉米、豆粕           规模化养殖           猪肉消费
  兽药疫苗          牧原/温氏/新希望         餐饮/零售
  种猪/仔猪                               深加工
```

**关键变量**:
1. **饲料成本**: 玉米2370元/吨低位, 利好养殖利润修复, 但当前猪价过低无法覆盖
2. **产能去化速度**: 决定猪周期拐点, 目前去化缓慢
3. **规模化率提升**: CR10(前10大企业出栏占比)持续提升, 周期波动或平滑

## 三、核心标的分析

### 3.1 牧原股份(002714) — 猪周期龙头, 底部磨底

| 指标 | 数值 | 判断 |
|------|:---:|------|
| 现价 | 38.47元 | 52周位25%(低位) |
| PE/PB | 22.7 / 2.65 | PE分位70%, PB分位仅1% |
| 市值 | 1262亿 | |
| 2025净利 | **154.9亿** | 盈利年(上半年猪价尚可) |
| 2026Q1净利 | **-12.1亿** | Q1同比-127.1%, 深度亏损 |
| 扣非/OCF | 待核实 | Q1猪价~14元/kg时已亏损 |

**治理质量**: 秦英林家族控制, 管理层稳定, "自繁自养一体化"模式区别于"公司+农户"。2025年盈利154.9亿主要受益于上半年猪价较高, 但Q1已转亏。资产负债率待核实, 前期扩张负债较高。

**投资逻辑**: 猪周期底部博弈。当前PB仅1%(52周分位), 估值极度压缩。若下半年猪价回升至15元/kg+, 全年仍有望盈利。但产能去化慢、拐点不确定是核心风险。

### 3.2 温氏股份(300498) — "公司+农户"模式

| 指标 | 数值 | 判断 |
|------|:---:|------|
| 现价 | 13.56元 | 52周位25% |
| PE/PB | 41.3 / 2.36 | PE极高(利润薄), PB分位6% |
| 2025净利 | 52.7亿 | 远弱于牧原 |
| 2026Q1净利 | **-10.7亿** | Q1同比-153.2% |

**对比牧原**: 温氏"公司+农户"模式在猪周期下行期抗风险能力更弱(需分担农户利润), 成本高于牧原。2025年净利52.7亿 vs 牧原154.9亿, 差距明显。

## 四、SOTA技术与前沿论文

- **精准养殖/智能养殖**: AI+IoT在猪场管理中的应用(体温监测、自动饲喂、疫病预警), 牧原等头部企业已大规模部署
- **基因编辑育种**: CRISPR技术在种猪改良中的应用研究(待核实: 中国是否有商业化进展)
- **饲料替代**: 低蛋白日粮技术(减少豆粕用量), 已在行业中推广
- **论文方向**: arXiv搜索未返回相关结果; 养殖/农业论文主要集中在《Animal Nutrition》《Journal of Animal Science》等专业期刊

## 六、总结与评级

| 维度 | 结论 |
|------|------|
| 猪周期 | 深度磨底, 猪价10.36元/kg, Q1全行业亏损, 拐点看Q3后期 |

**综合评级**: ⚠️ 谨慎观望

- 猪周期标的(牧原/温氏)适合左侧布局但需承受时间成本
- 安琪酵母(PE分位15%、Q1+15%)和金龙鱼(PE分位3%、Q1+51%)性价比更优
