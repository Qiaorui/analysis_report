# 机械设备行业调研报告

**报告日期：2026年8月7日 | 分析师：独立调研**

---

## 一、行业概览与宏观关联

### 1.1 行业定位

机械设备是典型的周期+成长双属性行业，下辖三大核心子板块：
- **工程机械**（挖掘机、起重机、混凝土机械等）：与基建/地产周期高度相关
- **机床**（数控机床、精密加工中心）：被称为"工业母机"，受益制造业升级与国产替代
- **通用设备**（液压件、轴承、紧固件等）：渗透于各制造环节

### 当前宏观相关性判断

| 宏观因子 | 2025年数据 | 对行业影响 |
|---------|-----------|-----------|
| GDP增速 | 5.0% | 经济整体平稳，制造业投资维持韧性 |
| 装备制造业增加值 | +9.2% | 显著跑赢工业整体(5.9%)，为机械设备核心利好 |
| 装备制造业利润 | +7.7% | 盈利能力恢复，但低于增加值增速，反映PPI下行压力 |
| 设备工器具购置投资 | +11.8% | 直接拉动机床、通用设备需求，设备更新政策持续发力 |
| 高技术制造业增加值 | +9.4% | 利好高端机床、精密设备等细分赛道 |
| PPI | -2.6% | 工业通缩持续，对设备价格形成压制，但降低成本端压力 |
| CPI | 持平 | 内需偏弱，终端需求恢复缓慢 |
| 房地产 | 70城中仅6城新房价格环比上涨 | 地产拖累工程机械内需的核心因素未根本改变 |

**关键判断：**

- **基建投资**：2025年设备工器具投资增长11.8%，表明基建端对机械设备的支撑力度较强。但房地产开发投资持续萎缩，新开工面积下降，对挖掘机、起重机等传统工程机械形成压制。基建的"结构性支撑"与地产的"总量拖累"并存。
- **融资13403亿（待核实）**：社融数据中若出现月度新增社融13403亿的水平，反映实体融资需求偏弱，对工程机械的终端购买力（按揭/融资租赁）构成间接压力。
- **A股震荡**：2026年上半年A股整体震荡，机械设备板块受"人形机器人"、"工业母机"等主题概念催化阶段性行情，但基本面驱动的持续性行情尚未形成。
- **制造业PMI（待核实）**：PMI持续在荣枯线附近波动，制造业企业资本开支意愿温和恢复，对机床等通用设备需求形成缓慢拉动。

### 1.3 周期位置判断

**工程机械：处于本轮周期底部区域，复苏信号初现**

| 指标 | 数据 | 信号 |
|-----|------|------|
| 2025年2月CMI指数 | 106.68，同比+13.53% | 开工回暖 |
| 恒立液压3月中大挖阀排产 | 同比+50%+ | 主机厂提前备产，预期二季度销量高增 |
| 三一重工2025年营收 | 897亿，+14.44% | 营收拐点已过 |
| 三一重工2025年净利润 | 84.08亿，+41.18% | 利润弹性显著大于营收弹性 |
| 设备更新政策 | 国三及以下排放标准挖机加速淘汰 | 更新需求释放 |

从三一重工的历史数据看，2021年为上一轮景气高点（营收1069亿，净利120亿），之后连续下滑至2023年（营收740亿，净利45亿）。2024-2025年逐步回升，但距离2021年高点仍有差距。**当前处于底部复苏初期，而非全面繁荣。**

上一轮完整周期参考：2009-2011年挖掘机销量从9.5万台飙升至17.8万台（四万亿刺激）→2012-2015年断崖式下跌至5.63万台→2016年开启新一轮周期。本轮周期的驱动因素更多元：设备更新、出口渗透、城市化建设、电动化替代。

**机床行业：处于底部磨底阶段，国产替代提供结构性支撑**

机床行业受制造业整体资本开支周期影响。2022-2025年，受下游需求疲软影响，行业整体承压。但高端数控机床（五轴加工中心等）受益于国产替代政策，呈现结构性亮点。

## 二、产业链拆解

### 2.1 工程机械产业链

```
上游（核心零部件）          中游（主机厂）            下游（应用）
├─ 液压件（油缸/泵阀）     ├─ 三一重工              ├─ 基建（公路/铁路/水利）
│  └ 恒立液压(77%挖机油缸) ├─ 徐工机械              ├─ 房地产（新开工/施工）
│  └ 博世力士乐(德)        ├─ 中联重科              ├─ 矿山（煤炭/金属矿）
├─ 发动机                  ├─ 柳工                  ├─ 农业（农田水利）
│  └ 潍柴动力/康明斯       ├─ 卡特彼勒(美)          └─ 海外工程（一带一路）
├─ 底盘/结构件             └─ 小松(日)
├─ 电控系统
└─ 回转支承
```

**产业链价值分布：**
- 液压元件是工程机械价值量最高的核心零部件，占整机成本约25-30%
- 液压油缸占液压件价值47%，液压泵阀占37%
- 历史上，高压油缸、泵阀、马达、液压阀四大核心件被日本KYB、德国博世力士乐等垄断，导致国内主机厂70%利润被上游吞噬（待核实）
- 恒立液压实现突破：挖掘机油缸国内市占率77%+，泵阀市占率35%+，全球每3台挖掘机有1台使用恒立液压部件

**核心产品分析：**

| 产品 | 市场格局 | 周期位置 | 关键驱动 |
|-----|---------|---------|---------|
| 挖掘机 | 三一/徐工/卡特彼勒三足鼎立 | 底部复苏 | 设备更新+出口 |
| 起重机 | 中联/三一/徐工主导 | 底部 | 风电吊装+基建 |
| 混凝土机械 | 三一全球龙头 | 温和复苏 | 基建+城市更新 |

### 2.2 机床产业链

```
上游（数控系统/功能部件）      中游（整机制造）         下游（应用）
├─ 数控系统                  ├─ 海天精工(龙门/五轴)   ├─ 航空航天
│  └ 发那科(日)/西门子(德)    ├─ 科德数控(五轴联动)   ├─ 汽车（新能源/传统）
│  └ 广州数控/华中数控(国产)  ├─ 创世纪(3C钻攻中心)   ├─ 模具
├─ 丝杠/导轨                 ├─ 日本马扎克/大隈        ├─ 3C电子
│  └ THK(日)/NSK(日)        └─ 德国DMG MORI          ├─ 军工
│  └ 恒立液压(新进滚珠丝杠)                           └─ 通用机械
├─ 主轴/轴承
│  └ NSK(日)/SKF(瑞典)
└─ 刀具/夹具
```

**国产替代现状（待核实具体数据）：**
- 中低端数控机床国产化率已达60-70%以上
- 高端五轴联动数控机床国产化率仍较低，主要依赖进口（日本、德国）
- 行星滚柱丝杠全球市场被瑞士Rollvis、德国GSA、瑞典Ewellix、德国Rexroth四家占据约80%份额，国内厂商合计仅占19%
- 数控系统高端领域，发那科、西门子仍占主导地位

**海天精工 vs 科德数控 vs 创世纪对比：**
- 海天精工：大型龙门加工中心为主，稳健经营，PE低(22.9x)，但增长乏力
- 科德数控：五轴联动数控机床纯正标的，技术壁垒最高，但体量小(营收5.5亿)，估值高(PE 84.8x)
- 创世纪：3C领域钻攻中心为主，营收弹性大但利润波动剧烈，PE畸高(205.8x)

### 2.3 通用设备

液压件、轴承、减速机、紧固件等通用设备渗透于制造业各环节。核心逻辑：
- **国产替代**：高端液压件、精密轴承等仍有较大替代空间
- **下游多元化**：工程机械+新能源+机器人+航空航天，分散单一行业风险
- **人形机器人新赛道**：行星滚柱丝杠（价值量占比19%，为上游最高）、减速器等成为新增长点

## 三、国际维度

### 3.1 工程机械出口与一带一路

中国工程机械出口持续增长，已成为行业核心增量来源：

| 维度 | 情况 |
|-----|------|
| 三一重工国际化 | 实施"数字化、电动化、国际化"三大战略，在美国、日本、印度、印尼等国设有工厂/公司 |
| 恒立液压海外收入 | 从2016年1.64亿→2021年12.35亿→2023年19.27亿，8年翻10倍+，目标海外营收占比50% |
| 一带一路 | 中国工程建设随一带一路走出国门，承建孟加拉国最大铁路项目、印尼雅万高铁等，盾构机产销量连续8年世界第一 |
| 全球竞争 | 三一已跻身全球工程机械制造商前列，与卡特彼勒(美)、小松(日)形成竞争 |

**风险提示：** 地缘政治风险（关税壁垒、技术封锁）、海外本地化经营风险、汇率波动。

### 3.2 机床国产替代

高端机床是全球制造业竞争的焦点领域：
- **日本/德国主导高端**：五轴联动加工中心领域，日本马扎克、大隈、牧野，德国DMG MORI占据技术制高点
- **中国加速追赶**：科德数控实现五轴联动数控机床国产化，但产能和精度稳定性仍有差距
- **出口管制风险**：高精度机床属于战略物资，部分高端产品受出口管制，自主可控需求迫切

### 3.3 全球制造业周期

- 2025年全球制造业PMI温和复苏，但区域分化明显
- 美国制造业回流政策推动设备需求，但对中国出口形成不确定性
- 东南亚、中东、非洲等新兴市场基建需求旺盛，利好中国工程机械出口
- 全球工程机械市场容量约2000亿美元（待核实），中国占比持续提升

## 五、论文/前沿技术

### 5.1 智能制造与数字化

> 注：因搜索工具限制，未能获取到2024-2026年最新arXiv论文的具体数据，以下基于行业技术趋势总结。

**关键前沿方向：**

1. **数字孪生（Digital Twin）**：在工程机械领域，通过建立设备数字孪生模型，实现远程监控、故障预测、运维优化。三一重工已建成全球重工行业首家"灯塔工厂"，将数字化贯穿研发-制造-服务全链条。

2. **AI+制造**：2026年6月央视报道指出"AI+制造"正释放无限可能，从"制造"到"智造"产业焕新加速。专家指出智能制造是长周期、高投入、强协同的系统工程。

3. **自主控制与无人驾驶**：挖掘机、装载机的自主作业和无人驾驶技术是工程机械智能化核心方向。涉及深度学习、计算机视觉、传感器融合等技术。

4. **液压系统能效优化**：恒立液压等企业持续推进液压系统节能技术，包括电液混合动力、负载敏感系统等，契合"双碳"目标。

5. **人形机器人核心部件**：恒立液压布局的行星滚柱丝杠是人形机器人重载关节核心驱动件。以特斯拉Optimus为例，14个线性关节中8-10个采用此零件。该领域的前沿研究涉及高精度加工、材料科学、摩擦学等。

6. **五轴联动数控技术**：科德数控等企业推进五轴联动数控机床的国产化和精度提升。关键技术包括：RTCP（旋转刀具中心点）控制、热误差补偿、振动抑制等。

**政策端：** 2026年4月新华网报道，我国加快制造强国建设，前2个月高技术制造业增加值同比+13.1%，装备制造业增加值+9.3%。"人工智能+制造"成为产业升级核心抓手。

## 六、投资建议与风险提示

### 6.1 投资建议

**核心判断：机械设备行业处于底部复苏初期，结构性机会大于系统性机会。**

| 标的 | 建议 | 逻辑 | 目标估值区间 |
|-----|------|------|------------|
| **三一重工** | ⭐ **关注（周期复苏）** | PE历史低分位(17%)，利润拐点确认，国际化对冲内需 | PE 20-25x对应19-24元 |
| **恒立液压** | ⚠️ **谨慎关注** | 国产替代+机器人双逻辑强，但董事长留置事件+估值高位(89%分位) | 需事件明朗化后再评估 |
| **海天精工** | ⭐ **低估值配置** | PE历史极低分位(7%)，安全边际高，Q1边际改善 | PE 20-25x对应17-20元(当前已接近) |
| **创世纪** | ❌ **回避** | 增收不增利，PE畸高(205x)，Q1继续下滑 | 需利润拐点确认 |
| **科德数控** | 👀 **长期跟踪** | 五轴国产化核心标的，但体量小估值贵 | 适合风险偏好高的投资者 |

**推荐组合（待核实具体仓位）：**
- **首选：三一重工** — 周期复苏+低估值+国际化，风险收益比最优
- **备选：海天精工** — 低估值安全边际，适合耐心持有等待制造业复苏
- **观察：恒立液压** — 等待董事长事件明朗化及估值回落至合理区间

### 6.2 风险提示

**宏观风险：**
- 房地产投资持续下行，拖累工程机械内需
- 制造业PMI持续偏弱，机床/通用设备需求恢复不及预期
- 基建投资力度不及预期
- PPI持续通缩，压制设备价格

**行业风险：**
- 工程机械周期复苏力度不及预期（底部可能延长）
- 机床国产替代进度慢于预期
- 行业竞争加剧，价格战风险
- 原材料（钢材等）价格大幅波动

**国际风险：**
- 地缘政治升级导致出口受限（关税、制裁）
- 海外贸易保护主义抬头
- 汇率大幅波动影响海外收入
- 一带一路项目执行风险

**个股风险：**
- **三一重工**：Q1增速放缓至+0.5%，需观察后续季度能否加速
- **恒立液压**：董事长留置事件为重大不确定性；PE处于历史高分位；丝杠业务商业化存不确定性
- **创世纪**：利润持续低于营收增长，盈利能力结构性偏弱
- **海天精工**：连续两年利润下滑，若制造业复苏推迟则可能继续承压
- **科德数控**：体量小（营收仅5.5亿），抗风险能力弱

**现金流与扣非提示：**
- 三一重工：2025年经营现金流需关注应收账款回收情况（待核实具体数据）
- 恒立液压：负债率仅18.6%，现金流质量预计较好；但大额分红后需关注资本开支能力
- 创世纪/海天精工：扣非净利润与归母净利润的差异需进一步核实（待核实）
