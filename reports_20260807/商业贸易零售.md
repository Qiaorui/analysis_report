# 商业贸易零售行业独立调研报告

> 调研时点: 2026-08-07 | 数据截至: 2026Q1 | 核心标的: 中国中免 / 永辉超市 / 家家悦

---

## 一、行业全景与宏观相关性

### 1.1 行业格局

中国零售行业2025年社会消费品零售总额约49万亿元，增速约3.5%。细分:
- 免税零售: ~700亿(中国中免占约70%+)
- 超市/大卖场: 传统大卖场持续关店，折扣店/会员店/社区超市崛起
- 电商: 线上渗透率约30%，增速放缓至5-8%
- 便利店/社区商业: 高增长

### 1.2 宏观相关性

- **消费复苏?**: **弱复苏**。社零增速3-4%，低于疫情前8%的水平。消费者信心指数仍偏低，储蓄率居高不下。
- **免税政策**: 2025年10月国务院发布《关于完善免税店政策支持提振消费的通知》，扩大免税店数量和品类，海南离岛免税额度维持10万/年。政策利好但效果受出境游分流影响。
- **出境游恢复**: 2025年出境游人数恢复至疫情前约80%，分流了海南免税消费(海外奢侈品价格优势+汇率因素)。
- **油价/金价**: 金价$4500+推升黄金珠宝消费(老凤祥/周大福受益)，但对超市/免税影响有限。
- **融资/流动性**: A股震荡下零售板块防御属性不强(非必选消费中偏弱)。
- **国务院"扩大消费十五五规划"**: 政策托底，但效果传导需要时间。

### 1.3 国际维度

- **免税**: 全球免税市场2025年规模约900亿美元。中国中免全球第一(按收入)，但面临韩国新罗/乐天、日本免税店竞争。海南免税vs. 海外免税(日韩/欧洲)价格竞争加剧。
- **零售变革**: Costco/山姆会员店在中国快速扩张，传统超市(永辉/大润发/家乐福)受冲击严重。
- **跨境电商**: TEMU/SHEIN颠覆全球零售格局，但对A股零售企业影响有限。

## 二、产业链分析

### 免税产业链
```
上游: 品牌供应商(奢侈品/化妆品/烟酒) → 全球采购
中游: 免税运营商(中免/深免/珠免/海旅) → 免税店运营
下游: 机场免税店 → 海南离岛免税 → 口岸免税 → 市内免税(待开放)
```

### 超市产业链
```
上游: 供应商(食品饮料/日用品/生鲜) → 自有品牌
中游: 超市运营(永辉/家家悦/高鑫零售) → 仓储会员店(Costco/山姆)
下游: 门店 → 到家(美团/饿了么/自有APP)
```

**关键变化**:
- **永辉调改**: 2024-2025年学习胖东来模式进行门店调改(提升商品力+服务+员工待遇)，部分门店效果显著(*待核实: 调改门店数量和销售数据*)。
- **折扣化**: 零食折扣(赵一鸣/零食很忙)、硬折扣超市(奥乐齐/盒马NB)快速扩张。
- **会员店**: 山姆/Costco在中国门店数持续增长，瞄准中产消费者。

### 3.2 盈利质量

| 指标 | 中国中免 | 永辉超市 | 家家悦 |
|------|---------|---------|--------|
| 2025营收(亿) | 536.9 (-4.9%) | 535.0 (-20.9%) | 96.5 (-) |
| 2025净利(亿) | 35.9 (-16.0%) | **-25.5**(亏损收窄) | 2.0 (-) |
| ROE | 6.5% | **-81.0%** | - |
| Q1净利(亿) | 23.5 (+21.2%) | 2.9 (+94.4%) | 1.5 (+7.0%) |

**关键发现**:
- **中国中免**: 2025年营收/净利继续下滑(-4.9%/-16.0%)，但Q1出现拐点(+21.2%)。可能受益于: (1)海南免税旺季 (2)政策效果显现 (3)低基数。ROE从2021年37.3%暴跌至6.5%，盈利能力大幅下台阶。PB 2.02x处于1%历史分位——极度破净区间(相对历史)。
- **永辉超市**: **连续五年亏损(2021-2025)**，累计亏损超120亿。2025年营收从786亿腰斩至535亿(大规模关店)。但Q1扭亏(+2.9亿)是重要转折信号——胖东来式调改初见成效？还是季节性因素？(*待核实: Q1扭亏的可持续性*)。PB 17.46x因连续亏损导致净资产大幅缩水而失真。
- **家家悦**: 山东区域超市龙头，深耕胶东半岛。营收/利润稳健(*2025年详细数据待核实*)，Q1净利+7%平稳增长。PE/PB均处低位(27%/5%分位)。

### 3.3 现金流与扣非

- 中免: 免税业务现金流好(现金销售为主)，OCF通常优于净利。
- 永辉: 连续亏损期间OCF仍为正(超市业态对供应商有账期优势)，但不可持续。
- *具体数据待核实*。

## 四、公司治理与风险

| 维度 | 中国中免 | 永辉超市 | 家家悦 |
|------|---------|---------|--------|
| 实控人 | 中国旅游集团(央企) | 张轩松/张轩宁(兄弟) | 王培江(家族) |
| 治理质量 | 央企治理规范，但效率偏低 | 创始人控制，战略摇摆 | 家族治理，区域深耕 |
| 质押率 | 低 | 高(张氏兄弟质押待核实) | 低 |
| 分红 | 低(盈利下滑后) | 无(亏损) | 稳定 |

**核心风险**:
- **中国中免**: 出境游恢复分流海南免税消费。市内免税政策落地慢于预期。免税牌照放开(深免/珠免等)加剧竞争。
- **永辉超市**: 五年亏损超120亿，Q1扭亏是否可持续是核心问题。胖东来式调改需要大量投入(员工加薪+商品升级)，在亏损背景下资金压力巨大。
- **家家悦**: 区域集中度高(山东>80%)，全国化拓展困难。

## 六、综合评估与投资建议

| 标的 | 评级 | 核心逻辑 |
|------|------|---------|
| 中国中免 | **中性偏积极** | Q1净利+21.2%确认拐点，PB处1%历史分位极度低估。但免税竞争格局恶化(牌照放开+出境游分流)，ROE从37%→6.5%的趋势需逆转确认 |
| 永辉超市 | **回避** | 连续五年亏损超120亿，Q1扭亏可持续性存疑。基本面极差，属高风险博弈品种 |
| 家家悦 | **中性** | 区域龙头稳健经营，估值低(PE 27%/PB 5%分位)。但成长性有限，适合纯防御配置 |

**行业总结**: 商业零售处于"传统零售出清+新业态崛起"的转型阵痛期。中免Q1拐点值得关注但需确认。永辉调改是积极尝试但财务风险仍高。消费复苏力度是行业核心变量。
