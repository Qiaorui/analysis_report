# 轻工制造行业独立调研报告

> 调研时点: 2026-08-07 | 数据截至: 2026Q1 | 核心标的: 欧派家居 / 太阳纸业 / 裕同科技

---

## 一、行业全景与宏观相关性

### 1.1 行业格局

轻工制造涵盖: 家居(定制家居/软体家具)、造纸(文化纸/包装纸/特种纸)、包装(纸包装/金属包装)、五金等。2025年行业总规模约6万亿元。

### 1.2 宏观相关性

- **房地产(核心变量)**: 家居与地产高度相关。2025年新房销售面积同比继续下滑(约-10%至-15%，待核实)，直接压制定制家居(欧派)和装修建材需求。欧派2025年营收-8.9%/净利-23.2%，连续两年下滑。
- **存量翻新**: 二手房交易+旧房翻新部分对冲新房下滑，但增量贡献有限。
- **造纸周期**: 造纸是周期行业，与宏观经济/PPI高度相关。太阳纸业2025年营收+3.1%/净利+4.8%，温和复苏。纸价低位运行。
- **油价**: 影响化工原料(塑料/涂料/胶粘剂)成本，间接影响家居/包装。
- **出口**: 包装(裕同科技)受出口订单影响，消费电子出口景气度传导。
- **以旧换新**: 家具以旧换新政策(2025年国补延伸至家具品类)效果有限(待核实: 实际拉动数据)。

### 1.3 国际维度

- **家居出口**: 中国家具出口约700亿美元(2025)，美国为最大市场。关税加征(部分品类25%)推动向越南/墨西哥转移。顾家家居/敏华控股已在越南建厂。
- **造纸**: 中国是全球最大造纸国，但废纸进口受限(2021年禁令)导致木浆依赖进口。太阳纸业在老挝布局林浆纸一体化。
- **包装**: 裕同科技为全球消费电子包装龙头(苹果/华为供应商)，受消费电子景气度影响。

## 二、产业链分析

### 定制家居产业链
```
上游: 板材(大亚/兔宝宝) → 五金(百隆/海蒂诗) → 封边条/胶粘剂
中游: 欧派/索菲亚/尚品宅配/志邦 → 区域品牌
下游: 新房装修(占比~50%) → 二手房翻新(~30%) → 工程渠道(精装房~20%)
```

### 造纸产业链
```
上游: 木浆(进口+自制) → 废纸(国内回收) → 化学品
中游: 太阳纸业/晨鸣纸业/玖龙纸业(包装纸) → 山鹰国际
下游: 文化用纸(印刷) → 包装用纸(瓦楞/箱板) → 特种纸
```

**关键变化**:
- **定制家居**: 行业从增量转存量竞争，价格战激烈(欧派/索菲亚推出低价套餐抢客)。整装渠道(与装修公司合作)成为新增长点。
- **造纸**: 行业集中度提升，小产能出清。太阳纸业林浆纸一体化(老挝基地)成本优势显著。
- **包装**: 消费电子(苹果链)需求波动直接影响裕同科技。

### 3.2 盈利质量

| 指标 | 欧派家居 | 太阳纸业 | 裕同科技 |
|------|---------|---------|---------|
| 2025营收(亿) | 172.3 (-8.9%) | 420.0 (+3.1%) | 161.0 (+9.2%) |
| 2025净利(亿) | 20.0 (-23.2%) | 32.5 (+4.8%) | 15.9 (+4.1%) |

| Q1净利(亿) | 1.5 (-49.7%) | 9.1 (+2.3%) | 2.5 (+1.9%) |

**关键发现**:
- **欧派家居**: **业绩加速恶化**。2025年净利-23.2%，Q1净利-49.7%(近乎腰斩)！地产下行对家居的冲击还在加深。PE 10.4x/ PB 1.09x处于历史极低(4%/1%分位)，但"低估值陷阱"风险大——如果业绩继续恶化，低PE会快速走高。ROE从2021年20.1%降至10.6%，趋势恶化。
- **太阳纸业**: 造纸周期底部温和复苏。2025年营收+3.1%/净利+4.8%，Q1延续(+2.3%)。PE 12x/PB 1.26x处低位(36%/3%分位)。老挝林浆纸一体化是长期竞争力。但造纸行业整体产能过剩，价格弹性有限。
- **裕同科技**: 包装龙头，2025年营收+9.2%/净利+4.1%，Q1平稳(+1.9%)。增收不增利(利润率下滑)需关注。PE 23x处66%分位，估值不便宜。

### 3.3 现金流与扣非

- 欧派: 经销模式OCF通常优于净利，但地产链应收账款风险增加(*待核实*)。
- 太阳纸业: 造纸企业重资产，折旧大→OCF通常高于净利。

## 六、综合评估与投资建议

| 标的 | 评级 | 核心逻辑 |
|------|------|---------|
| 欧派家居 | **回避** | Q1净利-49.7%极度恶化，地产链冲击远未结束。PE/PB虽处历史底部(4%/1%分位)，但是典型的"低估值陷阱"。需等地产企稳信号 |
| 太阳纸业 | **中性偏积极** | 造纸周期底部，估值低(PB 3%分位)，老挝一体化提供长期成本优势。但价格弹性有限，需等PPI拐点 |
| 裕同科技 | **中性** | 包装龙头地位稳固，但估值不便宜(PE 66%分位)，增速平稳缺乏弹性 |

**行业总结**: 轻工制造核心矛盾是"地产下行拖累家居+造纸周期底部"。欧派业绩恶化程度超预期，需回避。太阳纸业在造纸底部有防御价值。行业整体缺乏强催化。
