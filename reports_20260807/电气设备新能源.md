## 一、景气度与宏观相关性

### 1.1 政策面：十五五规划定调高景气

2026年3月发布的《十五五规划纲要》明确：

- **构建新型电力系统**：全面提升电力系统互补互济和安全韧性水平，优化全国电力流向和跨区域通道布局
- **加快智能电网建设**，完善城乡配电网
- **科学布局抽水蓄能，大力发展新型储能**
- 非化石能源发电装机容量已超过化石能源（标志性拐点）
- **新型储能**被列为战略性新兴产业关键技术创新方向
- **全国统一电力市场体系**基本建成

**国家电网"十五五"固定资产投资预计达4万亿元**，较"十四五"大幅增长。截至2026年1月已宣布该计划（待核实具体增幅比例）。国家电网已建成42项特高压输电工程，为全球最大特高压电网运营商。

### 1.2 宏观关联

| 宏观因子 | 当前状态 | 对行业影响 |
|---------|---------|-----------|
| 布伦特原油 | $83↑ (中东升温) | 间接利好——能源安全逻辑强化，加速新能源替代 |
| 金价 | $4500+ | 避险情绪升温，基建类防御性资产受益 |
| 融资余额 | 13403亿↓ | 市场震荡，成长股估值承压 |
| 特高压建设 | 加速期 | 直接利好——核心驱动变量 |
| 新能源并网 | 需求高增 | 配网+储能设备需求持续扩张 |

### 1.3 行业景气度判断

**景气度: 高↑**

- 电网投资处于"十五五"开局放量期，4万亿总投资对应年均约8000亿，显著高于"十四五"
- 特高压工程进入新一轮核准密集期（待核实具体项目数量）
- 新能源装机高增→并网配套设备（变压器、开关、储能）需求刚性
- 电力设备出口维持高增（思源电气2025年营收+39%部分来自海外）

### 1.4 油价/电价/基建投资传导链

```
油价上涨 → 传统能源成本上升 → 新能源替代加速 → 并网设备需求↑
                                               → 特高压通道建设↑
                                               → 储能配置需求↑
电价市场化 → 峰谷价差扩大 → 储能经济性提升 → 储能设备需求↑
基建投资 → 电网资本开支 → 一次设备(变压器/开关)量增
                          → 二次设备(保护/自动化)智能化升级
```

## 二、竞争格局

### 2.1 国际对比

| 维度 | 中国 | 欧洲(ABB/西门子) | 美国(GE/伊顿) |
|-----|------|-----------------|--------------|
| 特高压 | 全球领先(±1100kV) | 无商业化运行 | 无商业化运行 |
| 电网智能化 | 快速推进 | 成熟但分散 | 设备老化更新 |
| 储能装机 | 全球第一(锂电池主导) | 抽蓄为主+电化学 | IRA政策驱动增长 |
| 设备出口 | 成本优势+技术提升 | 品牌溢价 | 本土保护 |
| 市场份额 | 国内市场国企主导 | 全球前三 | 北美为主 |

### 2.2 产业链分析

**上游(原材料)**:
- 硅钢片(变压器核心材料): 宝钢、武钢主导，供应充足
- 铜/铝(导体): 大宗商品价格波动影响成本
- 绝缘材料: 国产化率高
- IGBT/功率半导体: 国产替代加速(中车时代、斯达半导)

**中游(设备制造)**:
- **一次设备**: 变压器(特变电工、中国西电、保变电气)、开关(平高电气、思源电气)、GIS组合电器
- **二次设备**: 继电保护/自动化(国电南瑞、许继电气、四方股份)
- **储能设备**: 锂电(宁德时代、比亚迪)、液流(大连融科)、PCS/EMS

**下游(应用/运营)**:
- 国家电网(最大买方，4万亿投资)
- 南方电网
- 五大发电集团+新能源运营商

### 2.3 集中度与竞争

- **二次设备**: 高度集中，国电南瑞+许继电气合计市占率>50%，国网体系内优势明显
- **一次设备(变压器)**: 中等集中，特变电工/中国西电/保变电气三家主导特高压变压器
- **开关设备**: 平高电气(GIS)和思源电气(民营)差异化竞争
- **储能**: 集中度下降中，锂电价格战激烈，液流/钠离子新路线崛起

### 2.4 产能周期

- 特高压设备: 产能偏紧，核准→建设周期2-3年，设备交付需提前1-2年
- 配电设备: 产能充裕，竞争激烈
- 储能电池: 结构性过剩(低端过剩，高端紧缺)

## 四、SOTA论文与技术趋势

### 4.1 最新arXiv论文(2026年8月)

1. **"The Benefits of an Integrated Approach for Stability-Constrained Power System Planning"** (2608.06349)
   - 核心: 提出将稳定性约束整合到电力系统规划早期阶段的方法
   - 意义: 随着逆变器型资源(光伏/风电/储能)渗透率提高，传统同步发电机的动态电压稳定性和惯性响应贡献被削弱，需要一体化规划方法
   - 对行业影响: 利好电网自动化和二次设备需求

2. **"Distributed Coordination for Transmission-Distribution Systems with Nonlinear Flexibility Aggregation"** (2608.06341)
   - 核心: 分布式能源高渗透下，输配电系统协调运行的新方法
   - 解决: 线性聚合模型可能错误分类AC可行运行点，非线性聚合成本过高
   - 对行业影响: 配电网智能化升级、虚拟电厂技术的学术前沿

### 4.2 技术趋势判断

| 方向 | 成熟度 | 投资含义 |
|-----|--------|---------|
| 特高压交直流混联电网 | 成熟/商业化 | 国电南瑞、许继电气直接受益 |
| 新型储能(锂电+液流+钠离子) | 商业化早期 | 思源电气储能业务增长，但竞争激烈 |
| 智能配电网/微电网 | 成长期 | 二次设备需求持续增长 |
| 电力电子化电网稳定性 | 研究→工程化 | 新型保护/控制设备需求 |
| 构网型储能(Grid-forming) | 示范阶段 | 下一代储能技术方向 |
| 电力设备出海 | 加速期 | 思源电气海外营收占比提升 |

## 五、催化剂与风险

### 5.1 上行催化剂

1. **特高压工程密集核准** — "十五五"开局年，若2026年下半年有多条线路获批，设备订单将集中释放
2. **国网招标放量** — 4万亿投资对应年度招标额大幅增长（待核实2026年招标数据）
3. **QFII/主权基金持续增持** — Templeton+MAS同步加仓平高、思源，可能带动更多外资流入
4. **电力设备出口超预期** — 一带一路国家电网建设需求+中国设备性价比优势
5. **储能政策加码** — 新型储能被十五五规划列为关键技术创新方向
6. **中东地缘升温** — 油价上涨→新能源替代逻辑强化

### 5.2 下行风险

1. **特高压核准低于预期** — 若项目审批节奏慢于预期，板块估值将承压
2. **国网投资结构变化** — 若投资偏向土建/线路而非设备，设备商受益有限
3. **原材料涨价** — 铜、硅钢等大宗商品价格上涨侵蚀毛利率
4. **行业竞争加剧** — 储能/配电设备领域价格战风险
5. **估值高位回调** — 思源电气PB 94%分位，增速一旦放缓将面临戴维斯双杀
6. **海外地缘风险** — 电力设备出口可能面临目标国安全审查
