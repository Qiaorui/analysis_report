# 纺织服装行业独立调研报告

> 调研时点: 2026-08-07 | 数据截至: 2026Q1 | 核心标的: 海澜之家 / 森马服饰 / 鲁泰A

---

## 一、行业全景与宏观相关性

### 1.1 行业格局

中国纺织服装行业2025年规模以上企业营收约5万亿元，出口约3000亿美元(全球份额约32%，下降中)。行业分化为: 制造出口(代工为主，向东南亚转移)和品牌零售(内需为主，国潮崛起)。

### 1.2 宏观相关性

- **关税/贸易战**: **核心变量**。美对华纺织服装关税累计超30%，直接削弱出口竞争力。越南/孟加拉/柬埔寨份额持续提升。但国内品牌(海澜/森马)以直营为主，出口敞口有限。
- **内需消费**: 社零增速放缓至3-4%，服装零售增速约2-3%(弱于社零)。消费降级趋势下，"性价比"成为关键词——森马(巴拉巴拉童装+大众装)受益。
- **棉花价格**: 国内棉花价格2025年稳定在15000-16000元/吨(待核实)，成本端相对平稳。
- **人民币汇率**: 贬值利好出口型纺织企业(鲁泰A出口占比>60%)。
- **人口结构**: 出生率持续下降(2025年约800万)，直接影响童装(森马巴拉巴拉)和女装市场容量。

### 1.3 国际维度

- **出口转移**: 纺织制造加速向东南亚转移，申洲国际(越南/柬埔寨)成为标杆。鲁泰A(色织布出口龙头)也在越南建厂规避关税。
- **品牌出海**: 安踏/李宁尝试东南亚开店但进展缓慢。SHEIN(快时尚跨境电商)颠覆行业格局，但非A股上市公司。
- **国际品牌在华**: ZARA/H&M/优衣库份额下降，国潮品牌(李宁/安踏/FILA)份额上升。

## 二、产业链分析

```
上游: 棉花/化纤 → 纱线 → 面料(鲁泰A色织布全球第一) → 辅料
中游: 品牌运营(海澜之家/森马/安踏/李宁) → 代工制造(申洲国际)
下游: 线下门店(购物中心/街铺) → 电商(抖音/快手直播占比提升至30%+)
```

**关键变化**:
- **渠道变革**: 抖音电商/直播重塑服装零售。森马在抖音渠道布局领先，线上占比持续提升。
- **柔性供应链**: "小单快反"模式兴起，ZARA模式本土化。
- **国潮**: 文化自信驱动国货品牌崛起，但热度从2021高峰有所回落。

**关键发现**:
- **海澜之家**: "男人的衣柜"，品牌+加盟模式(类平台化运营)。营收/净利2025年几乎零增长，增长动力不足。但PB 1.68x处于8%分位(历史低位)，股息率约5-6%(待核实)。
- **森马服饰**: 表现亮眼，2025营收+25.9%，净利+45.6%。巴拉巴拉(童装)贡献约60%收入，是增长引擎。Q1延续高增(+45.2%)。但ROE仅7.7%，盈利质量待提升。
- **鲁泰A**: 色织布出口龙头，出口占比>60%。2025年受益于人民币贬值+订单恢复，利润+44.7%。但Q1净利-36.9%(*待核实: 是否与出口订单季节性波动或关税升级有关*)。PB仅0.5x极度破净，市值仅35亿是小盘股。

### 3.3 现金流与扣非

- 纺织服装行业现金流季节性明显(Q4集中回款)。
- 海澜之家现金流较好(加盟模式先款后货)。
- 鲁泰A作为出口企业，OCF受汇率和账期影响波动较大。

| 维度 | 海澜之家 | 森马服饰 | 鲁泰A |

| 实控人 | 周建平(家族，>55%) | 邱光和(家族，>40%) | 刘石政(通过鲁泰集团) |
| 治理质量 | 家族控制，管理层稳定 | 家族控制，多品牌战略 | 国资背景，治理规范 |
| 质押率 | 中高(待核实) | 中(待核实) | 低 |
| 分红 | 稳定，股息率~5% | 较低 | 一般 |

**核心风险**:
- **海澜之家**: 库存问题是长期隐患(加盟模式下存货风险转嫁给加盟商，但品牌信誉仍受影响)。品牌老化问题。
- **森马服饰**: 童装依赖度高(巴拉巴拉)，若出生率持续下降将面临市场容量天花板。
- **鲁泰A**: 出口依赖度高，关税升级直接冲击。Q1净利-36.9%是重要警示信号。

## 五、论文与技术维度

- **功能性面料**: 智能穿戴/温控面料/抗菌面料是研发热点(待核实: arXiv/期刊论文)。
- **可持续纺织**: 再生纤维/生物基材料/旧衣回收技术(欧盟2026年将实施纺织品回收法规)。
- **AI设计/柔性制造**: AI辅助服装设计+数字化打版+小单快反，降低库存风险。
- **3D编织/无缝技术**: 减少浪费、提升效率。

## 六、综合评估与投资建议

| 标的 | 评级 | 核心逻辑 |
|------|------|---------|
| 海澜之家 | **中性** | PB 1.68x处8%分位低估，股息率~5%有防御性。但零增长+品牌老化制约上行空间。适合纯高股息策略 |
| 森马服饰 | **增持** | 2025年高增(营收+26%/净利+46%)确认复苏，Q1延续。巴拉巴拉童装品牌力强。但ROE偏低需注意 |
| 鲁泰A | **中性** | PB 0.5x极度破净，出口龙头有估值修复空间。但Q1净利-37%暴露关税冲击风险，小盘股流动性差 |

**行业总结**: 纺织服装处于"出口承压+内需弱复苏"格局。森马凭借童装+性价比定位表现突出。关税升级是行业最大下行风险，内需消费刺激政策效果有限。
