# 交通运输物流行业调研报告

> 时点: 2026-08-07 | 评级: ✅ 推荐(结构分化, 精选标的) | 核心标的: 中远海控/顺丰控股/京沪高铁

## 一、宏观相关性与景气度

### 1.1 航运: 中东局势升温, 运价高位分化

**宏观背景**:
- 中东升温, 布伦特原油$83↑
- 胡塞武装对红海航运威胁持续, 人民网报道"胡塞武装或控制曼德海峡"(2026年7月)
- 曼德海峡承载全球约12%贸易量, 若封锁将严重冲击亚欧航线

**航运细分**:
| 子板块 | 景气度 | 核心逻辑 |
|--------|--------|----------|
| 集运(集装箱) | ★★★★☆ | 红海绕行好望角, 运力紧张, 运价高位 |
| 油运(原油/成品油) | ★★★★☆ | 中东地缘+运距拉长, 运价受益 |
| 干散货(BDI) | ★★★☆☆ | 中国需求温和, BDI震荡 |

**中远海控Q1净利58.8亿, 同比-49.7%**: 虽下滑但仍处高位, 反映运价较2025年高点回落但仍高于历史中枢。招商轮船Q1净利27.6亿, **同比+219.3%**, 油运景气度极高。

### 1.2 航空: 暑运旺季但盈利承压

- 三大航(国航/东航/南航)2025年仍亏损或微利: 国航-17.7亿, 东航-16.3亿, 南航+8.6亿
- 2026Q1继续分化: 国航Q1盈利17.1亿(同比-183.9%基数高), 东航Q1盈利16.3亿(同比-264.1%)
- 航空业PE极高(国航62.6、东航81.9), 估值不合理
- 油价$83↑对航空成本端构成压力(燃油成本占30-40%)
- **吉祥航空Q1+27.7%**是亮点, PE 21.1合理

### 1.3 快递: 量增价降, 龙头分化

- 快递行业业务量持续高增(电商渗透率提升)
- 但单价持续下降, 价格战激烈
- **顺丰控股**: PE 15.4, PB分位1%, 2025净利111.2亿, Q1+13.0%, 高端快递+供应链龙头
- 中通/韵达等通达系单价竞争激烈(待核实具体数据)

### 1.4 铁路/公路: 高股息防御

- **大秦铁路(601006)**: PE 16.7, PB 0.59(破净), PB分位仅1%, 2025净利59亿, 股息率~6%
- **京沪高铁(601816)**: PE 18.5, PB 1.17, 2025净利131.7亿, Q1+6.0%, 核心资产
- **山东高速(600350)**: PE 16.2, PB 1.83, PE/PB分位均94%(历史高位)

### 1.5 国际维度

- 中东局势→油价↑→航运受益(运价)/航空受损(成本)
- 红海绕行→运力紧张→集运运价支撑
- 全球贸易量温和增长, 但贸易摩擦风险(关税)
- "一带一路"带动跨境物流需求

## 二、产业链分析

```
运输方式: 水路(海运/内河) / 铁路 / 公路 / 航空 / 管道
  ↓
细分行业:
  航运: 集运(中远海控) / 油运(招商轮船) / 干散货
  快递: 顺丰(高端) / 通达系(电商件)
  铁路: 大秦(煤运) / 京沪(客运)
  航空: 三大航(国航/东航/南航) / 吉祥/春秋
  公路: 高速公路(山东高速/宁沪高速)
  港口: 上港集团/宁波港(待核实)
```

**关键变量**:
1. **中东局势/红海**: 航运最大变量, 持续则运价维持高位
2. **油价**: 航运成本占比低(影响小), 航空成本占比高(影响大)
3. **快递单价**: 价格战是否缓解
4. **高铁分流**: 对航空中短途航线的替代效应

**投资逻辑**:
