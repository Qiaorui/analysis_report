# 社会服务教育行业调研报告

> 时点: 2026-08-07 | 评级: ⚠️ 谨慎观望(消费复苏乏力) | 核心标的: 首旅酒店/京沪高铁(归属交运)

---

## 一、宏观相关性与景气度

### 1.1 消费复苏: 弱复苏, 结构分化

- 社零增速温和(待核实: 最新月度数据)
- 服务消费复苏好于商品消费, 但增速放缓
- 旅游: 出游人次恢复至2019年水平, 但人均消费偏低("穷游"现象)
- 餐饮: 连锁化率提升, 但客单价承压
- 教育: "双减"后K12学科培训大幅萎缩, 职业教育/素质教育转型

### 1.2 子板块景气度

| 子板块 | 景气度 | 核心逻辑 |
|--------|--------|----------|
| 酒店 | ★★★☆☆ | 商旅恢复, RevPAR修复中, 但供给增加 |
| 旅游景区 | ★★☆☆☆ | 客流恢复但消费降级, 客单价下降 |
| 餐饮 | ★★☆☆☆ | 客单价承压, 同质化竞争 |
| 教育 | ★★★☆☆ | 职业教育政策利好, 但转型期业绩不确定 |
| 免税 | ★★★☆☆ | 出境游恢复分流, 海南免税政策竞争 |

### 1.3 国际维度

- 出境游恢复: 分流国内高端消费(日韩/东南亚/欧洲)
- 国际游客入境: 免签政策扩大, 入境游增量(待核实数据)
- 教育国际化: 留学恢复, 但地缘政治影响(美国签证)

### 1.4 宏观关联

- 消费信心指数偏低, 居民储蓄倾向高
- 房地产低迷→财富效应减弱→抑制消费
- 就业市场压力→年轻人消费降级

## 二、产业链分析

```
社会服务:
  旅游: 景区(三特索道) → 酒店(首旅/华住) → OTA(携程/同程) → 免税(中国中免)
  餐饮: 原材料 → 餐饮企业(绝味/海底捞) → 消费者
  教育: 教育内容/师资 → 培训机构(中公教育) → 学生/企业
  演艺: 内容制作(宋城演艺) → 景区/剧场 → 观众
```

## 六、总结与评级

| 维度 | 结论 |
|------|------|
| 消费复苏 | 弱复苏, 客流恢复但客单价承压, "穷游"现象明显 |
| 酒店 | RevPAR修复中, 首旅酒店估值低位(PB分位1%) |
| 旅游景区 | 客单价下降, 宋城演艺Q1-15.1% |
| 教育 | 转型期, 中公教育PE极高不合理 |
| 餐饮 | 竞争激烈, ST绝味亏损 |

**综合评级**: ⚠️ 谨慎观望

- **唯一推荐**: 首旅酒店(PB分位1%、Q1+18.5%), 酒店RevPAR修复+估值极低
- 宋城演艺PB分位1%但业绩趋势差, 观望
- 中青旅/中公教育/ST绝味不推荐
- 行业整体受消费复苏乏力制约, 不具备板块性机会
