## §1 行业景气度与现状

### 1.1 全球半导体行业总览

据德勤2026年3月发布的《2026全球半导体行业趋势报告》：

- **2026年全球半导体销售额预计达9750亿美元**，创历史新高，AI基础设施建设为核心驱动力
- SEMI数据：**2026年Q2全球硅晶圆出货量同比增长7.4%**，反映晶圆厂开工率回升
- 预计**2028年全球半导体设备销售额达2295亿美元**
- AI芯片（训练+推理）占增量贡献超40%，存储（HBM）与先进封装为瓶颈环节


### 2.3 产能周期判断

- **先进制程(<7nm)**: 全球产能紧张，TSMC/三星产能满载，中国大陆受设备限制扩张缓慢
- **成熟制程(28nm+)**: 中国大陆产能大幅扩张，2024-2026年为投产高峰，面临**产能过剩+价格竞争**风险
- **先进封装(CoWoS/Chiplet)**: 全球产能严重不足，TSMC CoWoS扩产中，长电科技等国内封测厂加速布局
- **设备**: 国产设备采购比例持续提升，北方华创/中微公司订单饱满，2026年设备国产化率目标提升至30%+（待核实）

### 2.4 景气分化核心逻辑

```
        AI芯片(高景气) ←→ 成熟制程(价格竞争)
              ↑                      ↑
         算力需求爆发           产能过剩隐忧

     英伟达中国供应链重塑      设备/材料国产替代加速
              ↑
     寒武纪/海光信息受益
```
