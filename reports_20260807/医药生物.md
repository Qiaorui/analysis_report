## 1. 行业全景

### 1.1 定义与分类

医药生物（申万一级行业）涵盖六大子板块:

| 子板块 | 代表领域 | 核心特征 |
|--------|----------|----------|
| **化学制药** | 创新药、仿制药 | 研发投入高, 专利悬崖, 集采压力 |
| **生物制品** | 疫苗、血制品、单抗/ADC | 技术壁垒最高, 增速最快 |
| **医疗器械** | 影像、IVD、高值耗材 | 国产替代+出海双驱动 |
| **医药商业** | 流通、零售 | 低毛利, 两票制后集中度提升 |
| **中药** | 创新中药、中药饮片 | 政策避风港, 集采温和 |
| **CXO/医疗服务** | CRO/CDMO、医院 | 外包渗透率提升, 周期波动 |

### 1.2 行业规模

- 中国医药工业总产值（2025年）: 约**4.5万亿元**, 同比增速约**5-7%**（来源: 工信部/中商产业研究院, 待核实精确值）
- A股医药生物板块（申万）: 上市公司约**500家**, 总市值约**6.5万亿元**, 占A股总市值约**7%**
- 核心标的市值合计: 恒瑞3484亿 + 迈瑞1834亿 + 药明康德3829亿 + 华东508亿 = **9655亿**

### 1.3 增长驱动力

1. **老龄化**: 60岁以上人口超3.2亿, 慢性病用药需求刚性增长
2. **创新升级**: IND申报量持续增长, 国产1类新药获批数逐年攀升
3. **出海加速**: License-out交易额屡创新高, ADC/双抗成为出海主力
4. **GLP-1革命**: 减肥/降糖赛道市场空间千亿美元级别

## 2. 当前宏观相关性判断

### 2.1 利率与降息预期

| 因素 | 对医药影响 | 传导机制 |
|------|-----------|----------|
| **降息预期** | ⬆️ 显著利好 | Biotech融资成本↓, DCF折现率↓→创新药估值↑ |
| **融资余额13403亿(降)** | 中性偏空 | 市场风险偏好降低, 成长股承压 |
| **A股震荡** | 分化 | 资金向业绩确定性标的集中 |

**核心逻辑**: 创新药属于长久期资产, 利率每下降25bp, 管线DCF估值可提升5-10%。今日创新药板块领涨, 降息预期是核心催化之一。

### 2.2 大宗商品与汇率

- **布伦特原油$83↑**: 化工原料成本上行, 影响仿制药毛利, 但对创新药影响有限
- **金价$4500+**: 避险情绪高涨, 医药作为防御板块配置价值凸显
- **人民币汇率**: 待核实当前值; 贬值利好CXO海外收入折算, 但增加进口设备/原料药成本

### 2.3 政策环境

| 政策 | 时间 | 影响评估 |
|------|------|----------|
| **国家基本药物目录2026版** | 2026年7月发布 | 调出老旧品种, 纳入更多创新药, 利好创新药企 |
| **集采常态化** | 持续推进 | 仿制药利润持续承压, 但边际影响递减 |
| **DRG/DIP支付改革** | 全面推进 | 医院控费, 利好性价比高的国产器械和创新药 |
| **创新药审评加速** | 持续 | CDE审评效率提升, 优先审评/突破性疗法通道扩容 |

> **来源**: 国家卫健委《关于印发国家基本药物目录（2026年版）的通知》(2026-07-09); NMPA/CDE官网

## 3. 国际对标

### 3.1 全球医药巨头对标

| 中国标的 | 国际对标 | 市值对比 | 差距分析 |
|----------|----------|----------|----------|
| **恒瑞医药** (3484亿≈$480亿) | 默沙东($5300亿) | 1:11 | 恒瑞管线深度不足, 全球化能力差距大 |
| **迈瑞医疗** (1834亿≈$250亿) | 雅培($2000亿) | 1:8 | 迈瑞海外占比仍低, 高端产品突破中 |
| **药明康德** (3829亿≈$530亿) | 龙沙Lonza($350亿) | 1.5:1 | 药明已超全球CXO龙头市值, 但BIOSECURE法案风险 |
| **华东医药** (508亿≈$70亿) | 诺和诺德($4500亿) | 1:64 | GLP-1赛道差距巨大, 华东仍在追赶 |

### 3.2 全球趋势

1. **ADC（抗体偶联药物）**: 全球最热赛道, 2025年全球销售额超$200亿, 中国企业（映恩/科伦/恒瑞）已成为全球ADC重要供给方
2. **GLP-1及其衍生**: 诺和诺德司美格鲁肽2025年全球销售额超$250亿, 成为"药王"; 中国GLP-1生物类似药正在追赶
3. **双特异性抗体**: 罗氏/安进/强生布局, 中国康方/信达等进入临床后期
4. **AI制药**: 英矽智能等进入临床阶段, AI显著缩短药物发现周期

### 3.3 中国差距与优势

**差距**:
- 原始创新(First-in-class)能力不足, 仍以Fast-follow/me-better为主
- 全球化商业能力弱, 大部分license-out仍依赖合作方海外销售
- 基础研究-临床转化链条不够通畅

**优势**:
- 临床试验成本仅为美国的1/3-1/5, 患者入组速度快
- ADC/双抗等细分领域已具备全球竞争力
- CXO产业链完整度全球领先
- 庞大患者基数支撑罕见病/大品种开发

## 4. 产业链分析

### 4.1 产业链全景

```
上游               中游                  下游
┌──────────┐    ┌──────────────┐    ┌─────────────┐
│ 原料药API │───→│ 制药企业      │───→│ 医院/终端    │
│ 药用辅料   │    │ (恒瑞/华东等) │    │ 零售药店     │
│ 包材       │    │              │    │ 互联网医疗   │
│ 实验动物   │    ├──────────────┤    └─────────────┘
│ 培养基/试剂│    │ CXO外包服务   │
└──────────┘    │ (药明康德等)  │    ┌─────────────┐
                ├──────────────┤    │ 医疗器械      │
┌──────────┐    │ 医疗器械企业   │───→│ 经销商       │
│ 核心零部  │    │ (迈瑞等)      │    │ 终端医院     │
│ 件/芯片   │    └──────────────┘    └─────────────┘
└──────────┘
```

### 4.2 各环节竞争格局

| 环节 | 集中度 | 壁垒 | 关键玩家 |
|------|--------|------|----------|
| **创新药研发** | 中(头部集中) | 极高(人才+资金+时间) | 恒瑞/百济/信达/君实 |
| **仿制药** | 低→中(集采加速) | 中(一致性评价) | 华东/齐鲁/科伦 |
| **CXO** | 高(药明系一家独大) | 高(客户粘性+产能) | 药明/康龙/凯莱英 |
| **医疗器械** | 中(国产替代中) | 高(注册证+渠道) | 迈瑞/联影/微创 |
| **医药流通** | 高(三巨头) | 低(资金+网络) | 国药/上药/华润 |
| **中药** | 中 | 中(保密配方) | 片仔癀/云南白药/同仁堂 |

### 4.3 产业壁垒分析

- **技术壁垒**: 生物药(单抗/ADC/CGT) > 化学创新药 > 高端器械 > 仿制药/仿制器械
- **资金壁垒**: 一款创新药从IND到上市平均需**10年+10亿元**(美元), 双抗/ADC略低
- **时间壁垒**: 临床审批周期长, 先发优势明显
- **政策壁垒**: 医保谈判/集采重塑竞争格局, 创新药以量换价

### 6.2 机遇

#### 6.2.1 创新药出海 (License-out)

- 2025年中国创新药license-out交易总额已超$500亿（待核实精确数据）
- ADC是中国出海最强势领域: 映恩生物、科伦博泰、恒瑞等多笔大额交易
- 双抗/多特异性抗体成为下一波出海热点
- 恒瑞连续7年入选全球制药50强, 国际化能力国内领先

#### 6.2.2 SOTA技术前沿（论文/学术维度）

**ADC (Antibody-Drug Conjugate)**:
- 新一代ADC采用可裂解linker + 高毒性payload(DXd/Dxd), 疗效显著提升
- 双载荷ADC、条件激活ADC(probody)进入临床
- 中国企业（映恩/科伦/恒瑞）在全球ADC临床管线中占比超30%

**GLP-1及多肽药物**:
- 口服GLP-1（如oral semaglutide高剂量版）已获批
- GLP-1/GIP/Glucagon三靶点激动剂(retatrutide)进入III期
- 中国企业: 华东医药(利拉鲁肽类似药)、信达生物(maridebart, 待核实)

**细胞与基因治疗(CG T)**:
- CAR-T疗法从血液肿瘤向实体瘤扩展
- 体内基因编辑(in vivo)技术突破, 碱基编辑/先导编辑进入临床
- 中国获批CAR-T产品已达5款+

**AI辅助药物发现**:
- AI将hit-to-lead周期从4-5年压缩至1-2年
- 英矽智能(AI管线药物)进入临床II期
- 大语言模型在靶点发现、分子设计中的应用加速

### 6.2.3 集采后的行业重构

- 集采已进行**10批**, 覆盖400+品种, 仿制药利润已被充分挤压
- 边际影响递减, 未中标品种降幅收窄
- 行业洗牌完成, 头部仿制药企(华东/齐鲁/科伦)凭规模+成本优势存活
- 集采倒逼转型: 华东/恒瑞均大幅增加创新药投入

### 6.2.4 CXO景气周期回升

- 全球新药研发投入回暖, 2025年全球CXO市场增速恢复至10%+
- 中国CXO从"量"转向"质": 从大量化学合成人员转向工艺专家+数字化/自动化工程师（来源: 发现工场 2026-06-02报告）
- 药明康德Q1 2026收入增速+26.7%, 确认行业回暖

### 6.2.5 宏观催化

- **降息预期**: 利好创新药长久期资产估值
- **金价$4500+**: 避险情绪下医药防御板块获配置
- **中东升温/油价$83**: 对行业直接影响有限, 但推升通胀预期→利好防御配置

## 核心结论

1. **创新药板块今日领涨的核心催化**: 降息预期(利好长久期资产) + 创新药出海持续突破(恒瑞III期成功等) + 基本药物目录2026版利好纳入创新药 + 集采边际影响递减; 药明康德+8.49%涨幅最大反映CXO景气确认回升。

2. **估值分化严重**: 四只标的PE分位均在5%或以下(药明除外), 但药明康德股价在52周99%高位; **华东医药**(PE 14.5倍/所有时间分位1.4%/PB历史最低)是估值安全边际最高的标的, GLP-1管线若兑现有估值重塑空间。

3. **风险提示**: 药明康德2025净利+102.7%含大额非经常损益可能(待核实扣非), 迈瑞医疗连续两季业绩下滑拐点不明, BIOSECURE法案仍为悬顶之剑; 短期追高药明康德风险大于收益, 恒瑞和华东医药的性价比更优。
