### ⚠️选取逻辑说明(2c是策展式选取, 非2b机械Top6)
2c的短期/中期Top6是**策展式选取**(催化窗口感知+避免短中期重复), 不是2b评分的机械Top6:
- **短期Top6**: 按2b短期分Top6本应是家电/银行/食饮/有色/**医药(5th,77.9)/农林(6th,77.5)**。但**医药/农林催化窗口是中期**(创新药出海兑现/猪周期拐点属3-6mo非1月事件), 短期催化偏弱, 故2c将其移至中期; 改选**公用(8th,76.3)/交运(10th,75.4)**——这两者短期催化更明确(高股息重估/顺丰鄂州机场), 且属防御短期品种。
- **中期Top6**: 选2b中期分Top中"短期Top6之外"的增量(独立α+周期底: 医药/农林/电气/机械/生物科技/建材), 避免与短期重复, 共展示12个不同板块。
- **2b短期分vs2c策展的差异是方法论使然**: 2b短期分权重催化30%但确定性15%+阶段契合25%会把催化弱但确定性强/阶段契合的板块(医药)推高; 2c策展用催化窗口感知override, 更贴近实际可操作性。两者不矛盾, 2b是分, 2c是选。

## 二、供应链串联(6条投资线)

把所选板块用 value-chain 逻辑串成投资线, 每条线标注**最强节点**(最该配的板块, 为Step3个股铺垫)。

### 线1: 加息降温防御线 ★最确定 (实际利率下行受益)
```
传导: 加息降温 → 实际利率/折现率↓ → 高股息资产重估
成员: 银行(息差政策底+股息5.35%) → 家用电器(格力股息5%+) → 食品饮料(茅台分红75%+) → 公用事业(长江电力3.44%)
最强节点: 家用电器(短中期双Top1, PE8/PB4%/股息5%+三重驱动, 性价比最优)
次强: 银行(招行PB6%+化债+ROE领先)
逻辑: 加息降温是2a核心宏观, 这条线短中期双优, 是当前最确定配置
```

### 线2: 独立景气α线 ★不依赖大盘β
```
成员: 有色金属(金: 央行购金+加息见顶,$4000地板) → 医药生物(创新药出海+ADC SOTA) → 农林牧渔(猪周期底+转基因)
最强节点: 有色金属(金, 短期最强α, 紫金Q1+97.5%+金铜锂三轮)
次强: 医药生物(恒瑞PB3%+出海兑现, 中期最强α)
逻辑: 不靠大盘β, 自身产业催化驱动; 加息降温对金/创新药估值双利好
```

### 线3: 高低切周期底部线 (资金避险流入端)
```
传导: AI挤泡沫 → 资金高低切 → 流入低估值周期底
成员: 建筑材料(海螺破净PB分位1%) → 钢铁(宝钢PB分位7%) → 轻工(欧派PB分位0%) → 房地产(保利PB分位1%)
最强节点: 建筑材料(海螺破净+碳市场扩围+利率敏感, 短中期双优72.5/74.3)
逻辑: 全板块PB分位<10%历史极低位, 是资金高低切的流入端; 地产链LPR期权是远期催化
```

### 线4: AI算力链 (待挤泡沫到位回补)
```
价值链: 芯片(英伟达/寒武纪) → HBM4(SK海力士) → 光模块(中际旭创) → 服务器(工业富联) → AI应用(金山办公/科大讯飞)
最强节点: 工业富联(PE28, AI链最便宜的价值锚, 用400亿利润验证景气)
状态: 7/28挤泡沫进行中(光模块PB分位97%暴跌-15%~-17%), 短期回避, 中期待Q3中报+Vera Rubin Q3出货验证
逻辑: capex绝对量级仍扩张+技术迭代未停, 中期景气延续; 但短期估值消化未到位
```

### 线5: 新能源链 (分化, 选环节)
```
价值链: 锂(赣锋/天齐) → 电池材料(华友/天赐) → 电池(宁德) → 整车(比亚迪/赛力斯) → 电网(国电南瑞/阳光电源)
最强节点: 电气设备(国电南瑞PB24%+特高压十五五1万亿, 新能源链中最确定)
次强: 宁德时代(40.7%全球份额穿越, PE分位16%)
逻辑: EV销量弱+碳酸锂反弹熄火压制β, 但储能LFP+特高压是结构高景气; 选电网/宁德, 回避比亚迪垂直依赖
```

### 线6: 资源/石油线 (停火后分化)
```
成员: 黄金(紫金/山东) — 牛市; 石油上游(中国海油) — 承压; 油服/海工(中海油服/海油工程) — 错杀
最强节点: 中海油服(PB分位2%极端低位+CAPEX滞后6-12月缓冲, 左侧逆向)
逻辑: 停火+油价$100→$82挤出地缘溢价; 金(货币/安全溢价)与油(工业需求)分化; 油服被错杀是错配机会
```

### 线7: 前沿主题卫星 (轻仓)
```
成员: 商业航天(长征十号乙) + 国防军工(建军百年2027) + 量子(Willow) + 生物科技(体内CRISPR) + 机器人(Optimus)
最强节点: 国防军工(中航光电PB分位0.41%历史极低+建军百年)
逻辑: 0→1颠覆性, 短期业绩兑现远, 严控仓位(<15%), 长线持有
```

### 归线补充说明(Top板块全覆盖)
- **非银金融**(2b短期75.0/中期75.4): 拆分归线 — **保险**(中国平安)归**线1加息降温防御**(投资端实际利率下行受益, NBV+28.5%); **券商**(中信证券)beta偏进攻, 短期谨慎但中期并购重组第二批+券商大年可配置。非银不在Top6但中期排名第9, 保险部分值得入线1卫星
- **交通运输物流**(2b短期Top6, 75.4): 归**线2独立α** — 顺丰(物流独立逻辑+鄂州机场, PB分位2%)与春秋航空(交运复苏, PB分位9%)均不靠大盘β, 属独立α
- **机械设备**(2b中期Top4, 77.1): 归**线3周期底部** — 工程机械周期复苏(三一Q1拐点)+设备更新+出海, 与建材/钢铁/轻工同属周期底+高低切流入端
- **钢铁**: 明确归**线3周期底部** — 宝钢PB分位7%/华菱1%, 与建材并列周期底, 碳市场扩围催化
- **电气设备归类澄清**: 电气设备同时具**线2独立α**(特高压"十五五"1万亿, 政策驱动非β)和**线5新能源链**(电网环节)双重属性。2c中列线5最强节点, 因其新能源链节点最强; 但其独立α属性使其也受益线2逻辑, 是跨线枢纽标的

## 三、配置思路(短中期, 为Step3铺垫)

### 短期1月(震荡偏弱+防御占优)
- **主仓(60%)**: 线1防御(家电/银行/食饮/公用) — 加息降温+低估值+高股息三重支撑
- **卫星(25%)**: 线2独立α(有色金/医药) + 线3周期底(建材) — 不靠β的α收益
- **机动(15%)**: 现金 — 等AI链挤泡沫到位或Q3中报验证

### 中期3-6mo(震荡筑底+逐步左侧)
- **主仓(50%)**: 线1防御 + 线2独立α(医药/农林/电气) — 确定性最高
- **卫星(25%)**: 线6油服错杀左侧 + 线3周期底(建材/地产期权) — 逆向布局
- **回补(10%)**: 线4 AI算力链(待Q3验证+挤泡沫到位) — 工业富联价值锚优先
- **前瞻(15%)**: 线7前沿主题(军工/航天) — 长期0→1, 严控

### 关键监测信号
1. **Q3中报窗口(8-9月)**: 防御(银行息差/家电以旧换新) vs 成长(AI硬件兑现度) 验证
2. **AI链挤泡沫到位信号**: 光模块PB分位回落+量能企稳 → 触发回补线4
3. **5年期LPR定向大幅下调**: 触发线3地产链/建材期权
4. **油价企稳$82+**: 触发线6油服左侧
5. **加息路径**: 若实际利率持续下行 → 线1/线2金/医药估值修复加速
